# 共振法阵 Resonance Sigil

H5 单页游戏：类幸存者 × 牌组构筑 × 空间编程。西幻像素风，480×270 逻辑画布，按屏幕尺寸整数倍原生渲染（大屏同样清晰）；摄像机跟随大世界，法术罗盘固定右下角。

**在线试玩**：<https://niangaol.github.io/Sigilweave/> ｜ **源码**：<https://github.com/Niangaol/Sigilweave>

## 快速开始

    npm install
    npm run dev      # 本地开发
    npm test         # 逻辑单测
    npm run build    # 静态构建，产物在 dist/
    node scripts/static-server.mjs dist 4174   # 零依赖静态验证服务器
    npm run sim      # 纯逻辑仿真，输出冷却与共鸣石实测数据
    node scripts/mow-fx-shot.mjs   # 割草密度 + 16 法术逐镜截图（Playwright，需先起 dev/preview）

## 目录

    src/logic/      纯逻辑内核（不依赖 Phaser，可在 Node 里直接跑）

### 操作速查

| 操作 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动，镜头随行 |
| 按住空格 | 暂停观察，松开继续（菜单/失焦暂停另算） |
| Esc → E | 暂停菜单进入法阵编辑，保留已有 CD；手牌每页五种、左右翻页 |
| 升级时点击卡牌或按 1/2/3 | 选一张进入手牌 |
| 暂停菜单 R / T | 重开 / 返回标题 |
| H / M | 标题玩法说明 / 合成音效开关 |

失焦会冻结战斗，回前台需手动继续。编辑完成回到暂停菜单，不自动恢复实时战斗。战斗内只有合成音效，过场/开场带程序化配乐（同随 M 开关）；移动端和人类新玩家试玩尚未覆盖。

### 辅助参数

- ?seed=xxx：固定种子，复现还需相同输入序列。
- **?quick=1：经验奖励倍率额外 ×4，不是每幕 15 秒，不自动跳过 Boss 或幕间。**
- ?scene=battle：跳过标题进入战斗；?pause=1：暂停截图辅助；?stress=1：性能压测入口（同时关闭过场）。
- ?scene=meta：直达残响祭坛；?resonance=999：验收用，临时灌 999 残响（不改真实存档语义）。
- **?cine=0：关闭过场、退回普通切场**，用于自动化/调试；正常游玩不要带。
- interval、starts、duo 仅是实验覆盖参数；不传参数才是上述默认大地图规则。
