# 共振法阵 Resonance Sigil

H5 单页游戏：类幸存者 × 牌组构筑 × 空间编程。西幻像素风，480×270 逻辑画布；摄像机跟随大世界，法术罗盘固定右下角。

**在线试玩**：<https://niangaol.github.io/Sigilweave/> ｜ **源码**：<https://github.com/Niangaol/Sigilweave>

## 快速开始

    npm install
    npm run dev      # 本地开发
    npm test         # 逻辑单测
    npm run build    # 静态构建，产物在 dist/
    node scripts/static-server.mjs dist 4174   # 零依赖静态验证服务器
    npm run sim      # 纯逻辑仿真，输出冷却与共鸣石实测数据

## 目录

    src/logic/      纯逻辑内核（不依赖 Phaser，可在 Node 里直接跑）
    src/scenes/     Phaser 场景
    src/entities/   角色、敌人、弹丸、掉落
    src/ui/         HUD 与面板
    src/data/       内容配置与卡牌数值唯一来源
    tests/          逻辑单测
    scripts/        仿真与辅助脚本
    docs/           计划、规则契约、内容规格、仿真报告

## 当前大地图版

> 当前规则见[规则契约](<docs/规则契约.md>)，本轮证据统一见[大地图验收记录](<docs/大地图验收记录.md>)。当前单测为 **17 个文件、599 项通过**；生产构建、九套浏览器回归、标准盘受阻率与 120 秒压测均通过。线上发布状态见验收记录的发布验证，不用旧版本 HTTP 200 冒充本次发布。

- **世界与探索**：三幕地图 1920×1440 / 2400×1600 / 2400×1800，镜头跟随玩家，HUD/罗盘固定。每幕 1 个 NPC + 2 个小 Boss 事件点，走近 28 像素自动触发，不再按幕中点定时出题。
- **法阵节奏**：6/12/16 格解封，**2/3/3 条脉流**，基础投射间隔 **1.4/1.2/1.0 秒**；角/边/中心基础 CD 为 0.8/1.1/2.2 秒，CD/间隔硬下限为 0.6/0.5 秒。
- **成长与奖励**：击杀和每 20 秒有效战斗时间给经验，升级时停三选一卡进手牌。宝箱给人物增益，Boss 有效收据给本幕法术与随机罗盘增益；人物和罗盘本体增益跨幕保留。新增二幕缝合尸魁、三幕咒誓主教两种精英。
- **通幕条件**：大 Boss 在等级 **5/8/11** 触发前置问答，答对直接解决、答错实战。小 Boss 按 mini 收据领奖后继续探索，不通幕；只有 major 收据对应的大 Boss 解决才结束本幕，第三幕大 Boss 解决后胜利。
- **构筑**：升级卡可通过暂停编辑装备；幕间仍有三轮三选一、铭文、誓约和出口编辑。拖放未做，采用点选手牌再点格子。

### 操作速查

| 操作 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动，镜头随行 |
| 按住空格 | 暂停观察，松开继续（菜单/失焦暂停另算） |
| Esc → E | 暂停菜单进入法阵编辑，保留已有 CD；手牌每页五种、左右翻页 |
| 升级时点击卡牌或按 1/2/3 | 选一张进入手牌 |
| 暂停菜单 R / T | 重开 / 返回标题 |
| H / M | 标题玩法说明 / 合成音效开关 |

失焦会冻结战斗，回前台需手动继续。编辑完成回到暂停菜单，不自动恢复实时战斗。只有合成音效、无配乐；移动端和人类新玩家试玩尚未覆盖。

### 辅助参数

- ?seed=xxx：固定种子，复现还需相同输入序列。
- **?quick=1：经验奖励倍率额外 ×4，不是每幕 15 秒，不自动跳过 Boss 或幕间。**
- ?scene=battle：跳过标题进入战斗；?pause=1：暂停截图辅助；?stress=1：性能压测入口。
- interval、starts、duo 仅是实验覆盖参数；不传参数才是上述默认大地图规则。

### 历史平衡问题

旧 2.0 秒间隔下冷却受阻率 0%、第三幕单脉流触发率 0.67 次/秒等，是旧参数实验，**不是当前默认值，也不是仍需等待拍板才能进入大地图的前置条件**。本版已采用 2/3/3 脉流与更快 CD/间隔，但人类节奏和平衡仍待试玩。
