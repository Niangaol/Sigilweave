# 共振法阵 Resonance Sigil

H5 单页游戏：类幸存者 × 牌组构筑 × 空间编程。西幻像素风，480×270 逻辑画布，桌面按屏幕取整数倍率出图（1080p 4 倍、1440p 5 倍），小屏走分数倍率 × 设备像素比，不靠浏览器拉伸糊图；摄像机跟随大地图，法术罗盘固定右下角。

**在线试玩** <https://niangaol.github.io/Sigilweave/> ｜ **源码** <https://github.com/Niangaol/Sigilweave>

脚下的 4×4 罗盘就是你周围的 16 个方位：脉流在格间跳跃，踩中哪一格，就朝那个方向出手。走位就是输出。

> 新手指引（灵宠墨宝）已接入：打开 <https://niangaol.github.io/Sigilweave/?review=1> 可跳过开场剧情直接看墨宝的开场引导；正常游玩不加参数，引导会在「选择初始套装」界面首次出现，`?guide=0` 关闭。
>
> **讲解即暂停**：每场开场的墨宝讲解期间，战斗像按了暂停键——主角仍站在地图上、背景照常渲染，但怪兽不会刷出、时间不推进；把讲解全部点完，怪兽才入场开打，战斗 BGM 也在这一刻响起。`?guide=0` 可整机关闭引导（此时直接开打、立即起乐）。

## 快速开始

```bash
npm install
npm run dev        # 本地开发
npm test           # 逻辑单测（vitest）
npm run build      # 静态构建，产物在 dist/
npm run preview    # 预览构建产物
npm run sim        # 纯逻辑仿真，输出冷却与共鸣石实测数据
```

产物脱离 Vite 独立验证：

```bash
node scripts/static-server.mjs dist 4174   # 零依赖静态服务器，打开 http://127.0.0.1:4174
```

沙箱 / 自动化环境（本机 DSH 工作区就是这么跑测试的）：

```bash
NODE_OPTIONS="--require ./scripts/sandbox-noexec.cjs" npx vitest run --pool=threads
```

`scripts/sandbox-noexec.cjs` 把 `child_process.exec` 换成空实现：工作区沙箱禁子进程时，vite 在 Windows 上会执行 `net use`，被拒就整场测试起不来；forks worker 同样起不来，所以要显式 `--pool=threads`。普通机器上直接 `npm test` 即可。

桌面版见[桌面打包](<docs/desktop-build.md>)：Electron 便携版走 `scripts/build-exe.ps1`，WinForms + WebView2 走 `scripts/build-webexe.ps1`，产物都不写注册表。

## 当前版本要点

- **五幕七场**：幕 1..5 是叙事单位，场 1..7 是玩法单位。场 1/2/3 各成一幕；第四幕 = 场 4 沉钟书库 + 场 5 衡律法庭；第五幕 = 场 6 熔星锻炉 + 场 7 破晓之座。场 1/2/3/5 的大 Boss 解决后通幕、进幕间工作台；场 4、场 6 原地换场（约 1.6 秒场次卡，不开工作台，保留血量、连斩、构筑与资源）；场 7 进结局与胜利结算。
- **法阵**：4×4 = 16 格，CD 硬下限 600ms、间隔硬下限 500ms。按幕解封 6/12/16/16/16 格、起始脉流 2/3/3/4/4、基础投射间隔 1.4/1.2/1.0/0.96/0.92 秒。共鸣石让正交四邻的间隔与冷却乘 0.75。
- **构筑**：24 张符印 + 6 辅助 + 4 铭文 + 3 誓约；4 种联组形状（对偶 / 直线三连 / 折线三连 / 环封四格）。卡牌数值只在 `src/data/cards.js`，场景里不写死。
- **法术的三层身份**：24 张符印里 20 张有锐 / 谐两种形态（锐：伤害 +30%、失去联组资格；谐：伤害 -18%、可联组），4 张只有基础形态；7 派系 + 4 元素反应（融化 / 导电 / 灼烧 / 净化）；48 条进化路线（24 × 2）；10 对专属连携。
- **首页主菜单**：标题页是六项竖排菜单（开始 / 残响祭坛 / 玩法说明 / 设置 / 档案 · 战绩 / 制作名单），↑↓ 与鼠标都能操作，底部常驻「残响 · 契约 x/34 · 最远第 N 幕」。玩法说明分七页（操作 / 罗盘 / 符印 / 构筑 / 敌情 / 成长 / Boss 与幕间）。设置里能关音效、屏幕震动、新手引导，存 `sigilweave:settings:v1`。
- **被动不再藏**：顶栏第二行常驻「被动 N · 增益 M」，Esc 暂停菜单底部列出本局已获的人物被动、罗盘增益与进化路线，各自带等级。
- **三职业起手**：疾风 / 烈焰 / 壁垒，各自固定 4 张开局法术 + 2 条本命被动。只改第一幕起手组合，解封格数与后续构筑三套一致。
- **敌人**：26 种（19 普通 + 7 天生精英），26 种行为一一对应；3 种变体（疾行 / 重甲 / 精英）按幕权重叠加，重甲带一次性护甲——伤害顺序固定「盾 → 甲 → 血」，唯一入口 `effects.applyDamage`。攻击是事件层：10 种带前摇的近战、10 种远程弹幕（含炮台 / 符文 / 召唤物），敌弹上限 96 / 20 / 12 / 8 / 16。
- **遭遇**：34 条题（7 NPC + 20 小 Boss + 7 大 Boss），全七场 27 个地图事件点；大 Boss 在等级 5/11/16/20/24/27/30 触发，答对免战、答错实战。
- **割草密度**：同屏上限 34→66，再乘按场密度系数（场 1 为 0.70，场 7 为 1.58，封顶约 104 只）；刷怪间隔 700→500ms、每波 1~2 只、受击无敌 1400ms；尸爆连锁、每 12 连斩回 1 血。密度按纯逻辑仿真定标（`scripts/density-sim.mjs`），不往死里堆。
- **残响祭坛（局外成长）**：死亡或通关折算残响 = 幕数×8 + 击杀/40 + 小 Boss×2 + 大 Boss×6 + 问答破局×4 + 通关 60（死亡 ×0.6、quick ×0.5，演武/压测/中途退出不结算）；11 条被动 × 5 级，消耗 10/24/48/80/120；34 个契约图鉴节点。存档 `sigilweave:meta:v1`，坏档静默收敛；首页主菜单第二项就是祭坛（`B` 仍可直达）。
- **画框**：480×270 最外圈 8px 雕花框，随血量陈旧化——血量高于 60% 完好，高于 30% 陈旧（3 道裂纹），再低进入濒碎（6 道裂纹、掉碎屑、四角渗血、1.1Hz 心跳脉动）。动画跟引擎时钟走，暂停与顿帧一起定格；竖屏不创建。
- **过场**：开场六镜 36 秒、8 类短过场 0.92–1.6 秒（boot / sigil / act / clear / death / victory / retry / return）、幕间出发 5.8 秒 journey、结局四镜 32 秒。目标场景在覆盖层底下就绪并暂停，揭开才放行，不黑屏不闪空帧；任意键可跳过（触发后 150ms 宽限）。

## 操作速查

| 操作 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动，镜头平滑跟随 |
| 按住空格 | 暂停观察（脉流与时钟一起冻结），松开继续 |
| Esc | 打开 / 关闭暂停菜单；编辑法阵时先退出编辑 |
| 暂停菜单里按 E | 进入法阵编辑，保留各格已有 CD，不能靠拆装刷新冷却；手牌每页五种、左右翻页 |
| 暂停菜单里按 R / T | 重开本局 / 返回标题（都要求菜单开着） |
| M | 音效开关，任何阶段都能按 |
| 升级时 1/2/3 或点击卡片 | 选一张进手牌（卡片进手牌，不自动上阵），并成为本场 1/2/3 技能 |
| 战斗中按 1/2/3 | 释放道具技能（见「断点存档与道具技能库」），用完进入冷却 |
| 标题页 ↑↓ / W S | 在六项主菜单里选：开始、祭坛、说明、设置、档案、名单 |
| 标题页 Enter / 空格 / 点击 | 确认当前项（第一项是开始，进初始套装选择） |
| 标题页 H / B | 直达玩法说明 / 残响祭坛（菜单里也有） |
| 标题页 C | 从断点存档继续上次冒险（有存档时状态条下方才出现这一行） |
| 标题页 Esc | 子面板里返回菜单 |
| 触屏 | 左侧方向键 + 单独暂停按钮；竖屏画布加高到 480×760 |

失焦会自动暂停，回前台要手动继续；编辑完成回到暂停菜单，不自动恢复战斗。拖放未做：选牌再点格子。

战斗内除了合成音效，还有一段程序化合成的热血像素战斗 BGM（152 BPM、方波主旋 + 三角贝斯 + 鼓点，`src/audio/BattleMusic.js`），墨宝开场讲解结束后随开打一起响起，换场/过场/死亡自动停；过场/开场另有自己的剧情配乐，二者互不重叠，都随 M 开关。

## 断点存档与道具技能库

- **断点存档**：每场进场、换场、通幕以及战斗中每 4 秒自动把本局进度写入浏览器 localStorage（`sigilweave:run:v1`）。中途退出后重新打开游戏，标题界面会在状态条下方多出一条「按 C 继续冒险 · 第 N 幕 · 第 N 场」，按 C 或直接点这一条即可从原场继续。死亡或通关会清档，不会留下已结束的局。仅本机有效，不跨设备同步。
- **道具技能库**：技能**完全来自升级三选一中玩家自己选的那张卡**——开局没有任何技能；三张牌里选攻击就是攻击技能，选「圣光壁垒 / 圣环」这类防御卡就是护盾技能（辅助卡没有主动法术，不占技能格）。选中的法术卡除进手牌外，登记进本场的技能库，占用底部 1/2/3 三格；之后选到的新卡会顶掉最早的一格。战斗中按对应数字键即可释放（自动锁定屏内最近敌人），释放后该格进入冷却（约 5.2 秒 × 卡牌冷却系数），冷却中格子变暗并显示剩余秒数。**每换一场技能库清零**，只留本场选到的技能；Boss 掉落的卡只进手牌，不进技能库。

## 调试与验收参数

| 参数 | 作用 |
| --- | --- |
| `?seed=xxx` | 固定种子；复现还需相同输入序列 |
| `?quick=1` | 经验倍率额外 ×4，不跳过 Boss、不跳过幕间 |
| `?scene=battle` / `?scene=meta` / `?scene=gameover` | 直达战斗 / 残响祭坛 / 结算排版调试页 |
| `?kit=bolt` / `flame` / `ward` | 指定起手职业，未知值回退疾风 |
| `?cine=0` | 关闭过场、退回普通切场，自动化用；正常游玩别带 |
| `?stress=1` | 性能压测入口，同时关闭过场 |
| `?resonance=999` | 验收用：把存档残响直接灌到 999（会写档） |
| `?pause=1` | 进战斗即暂停，截图辅助 |

`interval` / `starts` / `duo` 是实验覆盖参数，不传才是默认规则。

## 已知边界

- 仅合成音效，没有配乐素材库。
- 拖放未做，编辑与幕间都是点选。
- 人类新玩家试玩（乐趣、理解度、可读性）仍是最缺的一环，自动化测试替代不了。
- 桌面键鼠优先；触屏有竖屏重排与虚拟按键，但没有真机竖屏报告。
- Boss 差异主要是七套弹幕，未做多阶段与召唤机制。
