# P2 构筑演武闭环验收

> 工程闭环已通过自动化与真实浏览器验证；三名新玩家的理解度试玩尚未执行，因此不宣称 P2 的全部体验验收已完成。

## 可玩范围

- 地图仍为主画面，法术罗盘固定右下角；只有进入幕间才切到大尺寸编辑台。
- 三幕演武的解封数量为 6／12／16，脉流数为 1／1／2。
- 每次幕间三轮三选一，首轮保证输出；先选手牌再点符位安装，旧卡返回手牌，可拆卡重新放置。
- 主卡和辅助互斥；当前可通过选牌取得四张符印（飞弹、寒霜、烈焰、壁垒）和两张辅助（共鸣石、迟滞结界）。
- 碎片安装熔炉／中继铭文，每个 8；拆卸返还实际成本的60%向下取整，即4。旧的免费铭文不会凭空产生退款。
- 中继格不计入输出数量；至少保留两张非中继输出才允许出发，未领完奖励也不能出发。
- 快照、手牌、碎片与铭文实际支付记录跨幕保留，提交一次后才回到战斗。
- 构筑会影响真实战斗：熔炉伤害倍率、中继出发间隔与禁输出、共鸣石邻格变速、寒霜减速、迟滞近身减速、壁垒护盾与贴身伤害。
- 暂停显示实际最闲六格，幕间显示输出／辅助／空位、选中格的有效间隔和冷却及上幕统计。

## 时间与阶段边界

正常模式的三幕演武仍使用 180／240／180 秒。测试用 quick=1 每幕15秒，模式显式通过 URL 选择，不靠暗中改变时钟来完成回归。

**当前计时结束进入幕间或“演武完成”仅用于验证构筑流程，不是正式 Boss 关卡的替代。** P3 必须按新增设定将该节点替换为遭遇问答：答对可直接消灭正式 Boss，答错进入实战，Boss 被解决后才允许通幕。

尚未实现：NPC 问答、Boss、完整8＋6＋4＋4＋3内容、更多敌人、正式发布性能验收。沙漏／扩域已有派生逻辑和单测，但不在当前选牌池；献祭尚未实现。不能把配置定义数量算作可玩内容数量。

## 自动化证据

- npm test：5 个测试文件，**172/172 通过**，退出码0。
- npm run build：退出码0，JS gzip约347KB。
- 组合覆盖：构筑62、工作台52、逻辑23、结算10、运行集成25。
- 额外覆盖了非法伤害／护甲、固定落点不追踪、烈焰不跨地图选敌、寒霜与熔炉结算、直线联组只奖励末格、沙漏／扩域卸下不残留、中继禁输出与0.8秒下限，以及暂停时直接推进也不能偷跑时钟。

## 真实浏览器验证（系统 Edge＋Playwright）

针对生产构建的静态目录执行，避免 Vite 热重载干扰场景状态。

1. [工作台回归](<../scripts/workshop-smoke.mjs>)：自然完成第一幕，进入第二幕准备；12格解封、上幕记录一份；未领完不能出发；鼠标领取三轮奖励、装卡，进入第二幕后核对装卡结果保留。
2. 铭文交易专项明确使用16碎片测试夹具：安装熔炉16→8，拆卸8→12，再安装中继12→4；出发后中继的禁输出标记与4碎片均保留。**该16碎片来自测试夹具，不声称是短局自然赚取。**
3. [三幕回归](<../scripts/three-act-smoke.mjs>)：按顺序观测6格1脉流、12格1脉流、16格2脉流；经过两次幕间选牌，最终出现演武完成。
4. 快速演武最后结算的时间约45秒，统计累加三幕，不再只显示末幕15秒。上述浏览器脚本均无 pageerror，退出码0。

运行方式（先启动本地开发服务，另开终端）：

    node scripts/workshop-smoke.mjs
    node scripts/three-act-smoke.mjs

也可设置 BASE_URL 指向已启动的静态预览服务。脚本复用系统 Edge；若系统未装 Edge，需自行准备兼容 Playwright 的浏览器。Canvas鼠标测试给按下和抬起留60ms，避免同帧合并导致漏掉点击。
