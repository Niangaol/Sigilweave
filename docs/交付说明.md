> 桌面浏览器键鼠单页游戏。逻辑画布 480×270，按屏幕尺寸取整数倍率原生渲染（1080p 为 4×，1440p 为 5×），文字纹理同倍率生成，大屏不再靠浏览器拉伸糊图；摄像机跟随大世界，HUD 与右下角法术罗盘固定屏幕坐标。规则与参数见[规则契约](<规则契约.md>)；本轮测试和浏览器证据统一见[大地图验收记录](<大地图验收记录.md>)。

## 一、运行方式

开发模式：

    npm install
    npm run dev        # 默认 http://127.0.0.1:5173/，若占用以终端输出为准

静态交付：

    npm run build
    node scripts/static-server.mjs dist 4174
    # 浏览器打开 http://127.0.0.1:4174/

验收辅助参数（正常游玩不需要）：

- ?seed=xxx：固定随机种子；复现需同时保留相同指令与输入序列。
- ?quick=1：经验奖励倍率额外乘 4，用于加速等级流程；**不再表示每幕 15 秒自动通幕**。
- ?stress=1：压测入口，目标为 150 敌 / 300 弹丸 / 200 碎片；本版是否达到目标与实测帧时看本轮记录，不沿用旧数字。
- ?scene=battle：跳过标题直接进入战斗；?pause=1 可用于暂停截图。
- interval=1.2、starts=3、duo=0.08：实验对照参数，覆盖投射间隔、脉流起点数、对偶加成，不是默认平衡值。

## 二、操作

> **交互约定：所有需要“选”的地方都可以直接用鼠标点**（标题开始、选包卡片与出战按钮、升级三选一、遭遇选项与确认、暂停菜单四项、暂停编辑法阵、幕间工作台全部按钮、结算页再战）。键盘快捷键全部保留为等效操作，不是唯一入口。

| 按键/操作 | 作用 |
| --- | --- |
| WASD / 方向键 / 触屏方向键 | 在世界地图走位，镜头跟随（手机：竖屏大方向键、横屏左下角小键位） |
| 按住空格 | 暂停并观察法阵细目，松开恢复（菜单/失焦暂停另算） |
| Esc | 暂停菜单 / 手动继续 |
| 暂停菜单内 E | 打开法阵编辑（与幕间同款面板/图标/悬停），点选手牌再点格子放置；手牌五项一页、左右箭头切页 |
| 暂停菜单内 R / T | 重开本局 / 返回标题 |
| M | 合成音效开关 |

法阵盘面（战斗右下角罗盘与幕间编辑台）用同一套区位装饰帮助读盘：**角落 4 格**是黄铜护角 + 铆钉、**边上 8 格**是外侧单条黄铜围栏、**中心 4 格**是紫色符文方框。纯视觉，不影响数值与索敌。
| H | 标题页查看/关闭玩法说明 |
| 升级时 1/2/3 或点卡 | 三选一，卡牌进入手牌 |
| 鼠标 | 幕间构筑、辅助目标绑定、出口编辑、出发，及问答选择/确认 |
| 走近地图事件点 | 距离不超过 28 像素自动触发 NPC 或小 Boss 前置问答 |

失焦会暂停，回前台不会补算后台时间，需手动继续。实时战斗不能直接改阵；暂停编辑提交保留各格已有冷却截止时间，不靠拆装刷新 CD。完成编辑返回暂停菜单，不擅自恢复战斗。暂停编辑只处理主槽/辅助目标，铭文、誓约、出口仍在幕间处理。

## 三、地图探索与通幕闭环

1. **开局与法阵**：标题后选择起手套装。三幕分别解封 6/12/16 格，使用 **2/3/3 条脉流**；基础投射间隔 **1.4/1.2/1.0 秒**。位置基础冷却角/边/中心为 **0.8/1.1/2.2 秒**，最终冷却下限 0.6 秒、间隔下限 0.5 秒。
2. **大世界与镜头**：第一幕 1920×1440、第二幕 2400×1600、第三幕 2400×1800。出生在地图中心，镜头边界为世界，平滑跟随系数 0.12、死区 60×40；读题停跟随，关闭后恢复。攻击按角色相对的 4×4 条带结算，列/行都是覆盖全图的无界条带（内 2×2 是屏幕、外 12 条是屏幕外），因此屏幕外的敌人同样会被锁定；同屏杂兵上限 9→26 的抬升靠刷怪落点最小间距与逐帧分离控制拥挤，不会堆成一坨。
3. **沿途事件**：每幕固定 1 个 NPC 点和 2 个小 Boss 点，分在不同象限，靠近显示提示、走近自动触发，不再在“本幕中点”强制出 NPC。NPC 答对 +8 碎晶、治疗 15；答错迟缓 8 秒。
4. **小 Boss**：各幕分别为守墓傀儡、腐沼巨尸、裂瞳主教，每幕两处。先问答，答对直接解决，答错进入实战。小 Boss 解决后继续本幕探索，**不通幕**。
5. **升级与大 Boss**：击杀和有效战斗时间积累经验，升一级时停三选一卡进手牌，可通过暂停编辑装备。大 Boss 在玩家等级达到 **5/8/11** 时开启问答，而非 180/240/180 秒计时通幕。答对直接解除契约；答错实战。无需先清完全部地图事件点。
6. **分级收据**：大 Boss 按幕写 major 收据，小 Boss 按 bossId 写 mini 收据；重复解决不重复奖励。只有 major 解决才进入幕间，第三幕 major 解决才进入“契约终结”。
7. **幕间构筑**：固定三轮三选一，首轮基础四输出保底，后两轮完整 **16 符印 + 6 辅助**池（第二批新增连锁闪电、穿刺之矛、回声符文、余烬扇、地裂之颚、噬魂箭、圣环、陨星裁决；每个符印都有自己的 8×8 像素图标，盘面上可直接辨认）。点选手牌→点格子装卡，定向辅助需绑定邻格输出。每格两铭文槽，四种铭文单枚 8 碎晶、同名不重复；按实际支付成本退款 60% 向下取整（8→4，未知来源旧铭文 0）。可立一项誓约、编辑出口（断流格允许零出口）。三轮选完且至少两张非中继输出、构筑无错误才可出发。

## 四、经验、掉落与成长

### 经验和选牌

- 初始等级 1，当前等级 L 升下一级需要 round(6 × L^1.15) + 4 经验，HUD 同样显示当前等级的阈值；余量保留，等级经验跨幕继承。
- 普通杂兵基础经验 1、精英 6；每 20 秒有效战斗时间给基础经验 1。发放按经验倍率乘算后向上取整；暂停/读题/升级时不推进保底计时。
- 每级三张不同卡选一进手牌；连续升级逐次领取，不自动装牌。升级奖励与幕间三轮奖励互相独立。

### 掉落和本体增益

- 非 Boss 掉落基础碎晶：骷髅/蝠 1、腐尸/邪教徒 2、骑士 3、缝合尸魁 5、咒誓主教 8；18% 概率额外一颗，实际拾取才入账。
- 非 Boss 击杀 4% 概率掉人物增益宝箱，场上最多 6 个；距离小于 16 像素领取。池为生命上限 +20 且恢复 20、移速 +8%、拾取半径 +12、无敌时间 +0.15 秒、护盾上限 +10。人物增益跨幕保存，验证情况见[大地图验收记录](<大地图验收记录.md>)。
- 小 Boss 收据基础奖励 6 碎晶、大 Boss 12；答对另给小 Boss 6 / 大 Boss 4，所以答对合计 12 / 16，实战击败为 6 / 12。
- **每个小/大 Boss 有效收据另给 1 张本幕法术卡 + 1 项随机罗盘增益**。法术为一幕寒霜箭、二幕圣光壁垒、三幕星陨，均进入手牌；问答/战斗两条解决路径同享基础战利品。
- 罗盘增益跨幕保留：伤害倍率 +0.12（上限 1.6）、间隔倍率 ×0.92（下限 0.55）、冷却倍率 ×0.90（下限 0.55）、范围 +6（累计至 +18）、联组窗口 ×1.25（上限 2）、经验倍率 +0.15（上限 1.6）。实际毫秒数仍受 CD/间隔硬下限约束；间隔、CD 与联组窗口领取后现场更新。

### 敌人和双精英

- 常规敌人有骷髅、噬魂蝠、腐尸、邪教徒、亡灵骑士，另加二幕精英缝合尸魁（权重 8%）和三幕精英咒誓主教（权重 12%）。精英不是地图小 Boss，不写通幕收据。
- 缝合尸魁生命倍率 4.5、速度倍率 0.5，近身每 0.8 秒践踏；咒誓主教生命倍率 3.5，保持约 110 像素，每 4.2 秒瞬移，停顿 0.5 秒后以 0.15 秒间隔三连弹。
- 本幕前 180 秒线性提高基础生命 5→16、速度 20→40、在场上限 7→22，生成间隔 2400→1550 ms，再乘随机 0.85～1.15。
- 新生成敌人再受玩家等级 L 影响：生命 ×(1+0.16L)、伤害 ×(1+0.08L)、速度 ×(1+min(0.3,0.02L))，叠加敌种倍率。不是所有旧怪随升级瞬时重算。

## 六、已知限制（如实说明）

1. **无配乐**：只有 WebAudio 合成短音，没有背景音乐与音效素材库，M 可静音。
2. **拖放未做**：幕间和暂停编辑均为点选手牌再点格，不是拖拽。
3. **未做人类试玩**：自动化测试不能替代新玩家理解度、可读性、乐趣与平衡判断。
4. **联组诊断轻量**：已有触发/断链浮字与统计，不是完整逐实例回放或逐链解释面板，窗口超时未单独上报。
5. **移动端未适配**：桌面键鼠优先，无竖屏和触摸操作保证。
6. **Boss 差异主要是弹幕**：烬冠骑士扇形五连、溺誓女爵环封八向、无昼织王裂空七线，均有 600 ms 预警；未做多阶段、召唤机制。
7. **平衡仍待打磨**：本轮已提速 CD、间隔并增加脉流，旧“2 秒间隔下冷却几乎无效”属于历史参数问题，不是本版实测结论。不得据此宣称当前平衡已解决或爽感已验收。
8. **性能口径不能混用**：旧报告以 headless/软件渲染为主；本版大地图、探索事件与成长接入后的帧时、池容量表现及生命周期以本轮记录为准。伤害数字等文本特效未池化。
