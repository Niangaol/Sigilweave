# 共振法阵 · 精简首版交付说明

- 在线试玩：<https://niangaol.github.io/Sigilweave/>
- 源码仓库：<https://github.com/Niangaol/Sigilweave>
- 推送 main 后由 GitHub Actions 自动测试、构建并发布到 GitHub Pages。

> 桌面浏览器（键鼠）单页游戏。480×270 像素画布，全屏地图 + 右下角法术罗盘。

## 一、运行方式

开发模式：

    npm install
    npm run dev        # http://127.0.0.1:5173/

静态交付（产物在 dist/，相对路径，可放任意静态托管）：

    npm run build
    node scripts/static-server.mjs dist 4174   # 本项目附带的零依赖验证服务器
    # 浏览器打开 http://127.0.0.1:4174/

验收辅助参数（可选，正常游玩不需要）：

- `?quick=1`：每幕 15 秒，快速走完三幕流程
- `?seed=xxx`：固定随机种子，复现同一条脉流轨迹
- `?stress=1`：性能压测入口（150 敌 / 300 弹丸 / 200 碎片）
- `?scene=battle`：跳过标题直接进战斗
- 平衡对照（仅实验用途，默认值不变）：`interval=1.2`（间隔秒数）、`starts=3`（起点数）、`duo=0.08`（对偶加成）

## 三、玩法闭环

1. **三幕流程**：每幕 6→12→16 格解封、1→1→2 条脉流；脉流在格间跳跃，触发对应符印攻击玩家周围 4×4 方位区域。
2. **沿途问答**：每幕中点遇到一名 NPC，三选一。答对 +8 碎片并治疗 15 点；答错 8 秒迟缓诅咒。线索只来自当次对白与碑文。
3. **Boss 前置问答**：每幕计时结束，Boss 登场并先出题。答对呼出真名／割断誓绳，**直接消灭 Boss、免除整场战斗**；答错进入真实 Boss 战（600ms 瞄准预警 + 五向扇形弹幕）。
4. **幕间构筑**：三轮三选一奖励；点选手牌→点符位放置；定向辅助需再点相邻输出符印绑定目标；可安装熔炉／中继／断流／静默铭文（8 碎片，拆除返 4）；可立一个誓约；**出口编辑**可逐格开关四向出口（断流格允许零出口）。
5. **通关结算**：三个 Boss 均被解决后进入“契约终结”，记录破局／战斗击败方式与三幕累计统计。

内容规模：8 符印、6 辅助、4 铭文、3 誓约、5 种杂兵（骷髅／噬魂蝠／腐尸／邪教徒／亡灵骑士，按幕权重混刷）、3 位 Boss。

## 五、已知限制（如实说明）

1. **只有合成音效，没有配乐**：触发、吞跳、联组、受击、问答、Boss 陨落均有 WebAudio 合成短音，可按 M 静音；没有背景音乐与音效素材库。
2. **未做人类试玩**：3 名新玩家的理解度测试没有执行，自动化脚本不能替代可读性与乐趣判断。
3. **联组诊断仍偏轻量**：战斗浮字会显示断因与形状（如“冷却受阻（折线三连）”），幕间报告有按原因/形状统计；但还没有停下来的逐实例解释面板，窗口超时导致的断链也未单独上报。
4. **拖放未做**：幕间用“点选手牌→点符印格”放置，不是拖拽。
5. **杂兵掉落统一**：所有敌人固定掉 1 颗碎片（18% 额外 1 颗），没有按种类区分。
6. **性能口径**：性能数字来自 headless Edge 软件渲染；Firefox 已跑通布局与三幕全流程（功能正确性），但未采帧率，也未在真实 GPU 桌面环境复测。120 秒长时压测已完成（p95 3.5ms、最大帧 19.8ms）。弹丸与碎片已池化（容量 300/200，饱和有计数），伤害数字等文本特效未池化。
7. **移动端不支持**：首版桌面键鼠优先，竖屏与触摸未适配。
8. **Boss 行为单一模板**：三位 Boss 共用“追击 + 预警扇形弹幕”，差异主要在数值与问答内容。
9. **平衡未经打磨**：数值来自设计稿与仿真首版，冷却在 2.0s 基础间隔下几乎不生效（见 [仿真报告](仿真报告.md)），属于已知设计问题。
