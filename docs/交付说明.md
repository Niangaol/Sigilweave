# 交付说明 · 五幕七场

> 这一版交付的是能从头玩到结局的完整循环：五幕七场探索、34 条遭遇、局内构筑、局外残响成长，以及两条桌面打包路线。
> 下面按「交付了什么 → 怎么跑 → 怎么验收 → 已知限制」写，命令都能直接复制到仓库根目录的终端里执行。

## 一、这一版交付了什么

| 能力 | 现状 |
| --- | --- |
| 主循环 | 标题 → 选套 → 七场探索（问答 / 小 Boss / 大 Boss / 换场或幕间）→ 结局结算；480×270 逻辑画布，摄像机跟随大地图，罗盘固定右下角 |
| 幕与场 | 5 幕 7 场，幕 1→场 1、幕 2→场 2、幕 3→场 3、幕 4→场 4+场 5、幕 5→场 6+场 7；全流程 4 次幕间、2 次原地换场 |
| 构筑 | 24 符印 + 6 辅助 + 4 铭文 + 3 誓约，4×4 罗盘 16 格；24 张法术里 20 张有锐/谐两形态，48 条进化，7 派系 / 4 元素反应 / 10 专属连携 |
| 遭遇 | 34 条：7 个 NPC、20 个小 Boss、7 个大 Boss；答对免战给奖励，答错进战 |
| 敌人 | 26 种（19 普通 + 7 天生精英），3 种变体（疾行 / 重甲 / 精英）叠在基础怪上，另有近战、远程、炮台、符文、召唤五类攻击层 |
| 成长 | 局内等级、经验粒子、三选一升级、每 20 秒保底经验；局外 11 条被动各 5 级、34 个契约节点 |
| 表现 | 像素画框三级磨损、连斩与震屏、法术特效、开场与结局过场、8 类短过场 |
| 存档 | 只有局外档（残响、被动等级、契约节点、统计），写入浏览器 `localStorage` 或桌面版的本地目录 |
| 发布 | H5 静态包、Electron 便携版、WinForms + WebView2 绿色版 |

## 二、怎么跑

环境：Node.js（Vite 8 要求 20.19 以上或 22.12 以上）与 npm，Windows 上 bash 或 PowerShell 都行；浏览器验收要本机装了 Edge（或用 `PW_CDP_URL` 连一个已开调试端口的 Chromium）。

| 目的 | 命令 |
| --- | --- |
| 装依赖 | `npm install` |
| 开发服务器（热更新） | `npm run dev` |
| 生产构建 | `npm run build` |
| 预览构建产物 | `npm run preview` |
| 纯静态起服务 | `node scripts/static-server.mjs dist 4174` |
| 无头数值模拟 | `npm run sim` |

`npm run dev` 会在终端打印本地地址；静态服务脚本的第二个参数是端口，换成 4173 / 4174 都行。构建输出在 `dist/`，可以直接丢到任意静态托管上——线上试玩地址就是 GitHub Pages。

## 三、怎么验收

### 3.1 单元测试（基线 86 文件 / 1774 项全绿）

```bash
npm test
```

Windows 上如果 vitest 起 worker 时被系统调用卡住（`net use` 被拒、forks 起不来），用这条：

```bash
NODE_OPTIONS="--require ./scripts/sandbox-noexec.cjs" npx vitest run --pool=threads
```

`sandbox-noexec.cjs` 把 `child_process.exec` 换成空实现，`--pool=threads` 避开 forks worker。看到 `Test Files 86 passed`、`Tests 1774 passed` 就是全绿。

### 3.2 浏览器端 16 项冒烟

```bash
npm run build
node scripts/static-server.mjs dist 4173 &
BASE_URL=http://127.0.0.1:4173 node scripts/acceptance.mjs
```

依次跑布局、工作台、遭遇与按钮状态、移动端、五幕、成长、选套、说明页、暂停编辑、奖励、索敌、指针、平衡、压测、割草特效共 16 个脚本。全过打印 `ACCEPTANCE_ALL_PASS 16`；任何一个失败会非零退出并打印 `ACCEPTANCE_FAILED`，同时保留失败截图。默认 `LONG=1` 跑完整时长，调试时设 `LONG=0` 缩短。

### 3.3 残响祭坛冒烟

```bash
node scripts/meta-smoke.mjs
```

用 Playwright 起 Edge，开 `?scene=meta&resonance=999`，断言余额、页签、11 条被动初始等级，并把被动页、升级后、上限提示、契约图鉴四张截图写到 `docs/`。

需要真实 CDP 链路时（服务在 4174、调试端口 9333）：

```bash
node scripts/meta-cdp-check.mjs
```

断言链：初始 → 升一级扣 10 → 升到上限被拦「需先首杀对应契约主」→ 图鉴 0 解锁 → 结算页残响行。输出 `META_CDP_OK` 即通过。

### 3.4 桌面版

Electron 便携版（约 371MB，产物 `release-out/Sigilweave-win32-x64/`）：

```bash
npm run build
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build-exe.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify-run.ps1
```

WinForms + WebView2 绿色版（约 3MB，产物 `release-web/Sigilweave/`）：

```bash
npm run build
powershell -ExecutionPolicy Bypass -File scripts\build-webexe.ps1
node scripts/verify-webexe.mjs
```

两条路线都只出 win32-x64。打包细节、端口与目录约定见[桌面打包](<desktop-build.md>)，这里不重复。

## 四、怎么判断「这一版能交」

- `npm test` 全绿，且数字是 86 个文件 / 1774 项，不是更少。
- 16 项冒烟全过，`docs/` 下的截图是本次跑出来的，不是历史文件。
- 从标题开一局，能走到结局或死亡结算，结算页出现「残响 +N ／ 残响累计 M」。
- 按 B 进祭坛，能升级一条被动，Esc 回标题再进来，等级还在。
- 两条桌面路线至少一条双击能玩；异常时「启动（兼容模式）.cmd」能起。

## 五、数值基线

| 项 | 值 |
| --- | --- |
| 玩家 | 生命 100、移速 96、碰撞半径 6、受击无敌 1400ms |
| 法阵 | 4×4 = 16 格；冷却下限 600ms、间隔下限 500ms |
| 幕级节奏 | 间隔 1.4 / 1.2 / 1.0 / 0.96 / 0.92s，起始脉流 2 / 3 / 3 / 4 / 4，解封 6 / 12 / 16 / 16 / 16 格 |
| 难度曲线 | 180 秒内生命 4→12、移速 38→60、刷怪 700→500ms、同屏 34→66、伤害 3→5、每波 1→2 |
| 场系数 | 场 1~7 密度 0.70 / 0.88 / 1.05 / 1.20 / 1.34 / 1.46 / 1.58 |
| 大 Boss | 触发等级 5 / 11 / 16 / 20 / 24 / 27 / 30 |
| 敌弹上限 | 弹丸 96、召唤 20、炮台 12、符文 8、追踪 16 |
| 成长 | 升级需求 `round(30 + 4 × (L − 1))`；小 Boss 收据 6、大 Boss 12 |
| 残响 | 幕×8 + ⌊击杀/40⌋ + 小×2 + 大×6 + 问答×4 + 通关 60，死亡 ×0.6、quick ×0.5 |

这些数来自 `src/logic/constants.js`、`src/data/roster.js`、`src/logic/progression.js`、`src/data/meta.js`，改动后跑 `npm test` 会直接拦下来。

## 七、已知限制

| 限制 | 说明 |
| --- | --- |
| 没有局内存档 | 一局只在内存里，中途关页或刷新即丢，且不结算残响；重开只能从标题再来 |
| 局外档只在本机 | 写入浏览器 `localStorage`（键 `sigilweave:meta:v1`）或桌面版本地目录，不跨设备同步 |
| 只有合成音效 | 音效是现场合成的，没有配乐与音量滑杆 |
| 只有 win32-x64 | 没有 macOS / Linux 包，没有签名，没有自动更新 |
| Boss 只有一套弹幕 | 七位契约主各一套弹幕，没有多阶段、没有召唤小怪 |
| 触屏缺真机报告 | 手机横竖屏有布局冒烟，但缺少真机长期试玩结论 |
| 编辑靠点击与键位 | 法阵编辑没有拖放，只有选卡、点格、选目标这套流程 |
| 人类试玩样本少 | 数值靠模拟与冒烟守住，难度曲线仍缺足够多的真人样本 |

细节到字段的逐项检查见[试玩清单](<试玩清单.md>)；规则口径见[规则契约](<规则契约.md>)；幕场结构与遭遇清单见[五幕七场](<五幕七场.md>)；局外成长见[残响祭坛](<残响祭坛.md>)；模块划分见[技术架构](<技术架构.md>)。
