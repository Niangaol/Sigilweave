## 一、目标

从仅有设计稿的目录出发，做出一个桌面浏览器可完整游玩的精简版本。

成功标准：玩家能通过改阵改变火力方向、触发节奏和联组表现，并感知到这些变化如何影响走位与生存。

首版包含：1 角色、1 场地、三幕流程、幕间选牌与改阵、碎片成长、胜败结算、暂停、重开；新增沿途 NPC 问答和部分 Boss 的固定前置问答。答对可直接消灭正式 Boss，答错进入实际 Boss 战，题目依据游戏内线索与规则。该新增系统尚未实现。

不纳入首版：联网、账户、排行榜、局外成长、战斗中改阵、复杂 Boss、分裂与镜映脉流、物理祭坛、外圈大联组、正式移动端。

## 二、技术方案

| 项目 | 选型 |
| --- | --- |
| 引擎 | Phaser 3.90（锁定 3.x，npm 默认会装 4.x，已回退） |
| 语言 | 原生 JavaScript + ES Modules |
| 构建 | Vite 8 |
| 测试 | Vitest 5（逻辑）+ Playwright（流程，后续） |
| 分辨率 | 480x270 逻辑画布，整数倍放大，pixelArt + roundPixels |

分层：

    src/logic/      纯逻辑内核，不依赖 Phaser，可在 Node 里单测与仿真
      constants.js  全局常量与数值表
      rng.js        确定性随机源
      queue.js      (time, seq) 稳定优先队列
      grid.js       4x4 拓扑、邻接、出口、间隔与冷却推导
      combo.js      联组形状生成与严格时序判定
      sector.js     4x4 近远区域索敌
      engine.js     脉流引擎主循环
    src/scenes/     Phaser 场景：Boot / Title / Battle / Intermission / Result
    src/entities/   角色、敌人、弹丸、掉落
    src/ui/         HUD、法阵面板、卡牌与结算界面
    src/data/       内容配置（对应 docs/内容规格表.md）
    tests/          逻辑单测
    scripts/        仿真与构建辅助脚本
    docs/           计划、规则契约、内容规格、仿真报告

数据流：幕间草稿 → 校验 → 提交不可变构筑快照 → 重建派生值 → 模拟推进 → 事件 → 战斗结算与表现 → 统计报告。渲染订阅事件，不能反向决定玩法。

## 四、验收标准

### 逻辑正确性（已自动化）

- 同一 seed 在 16ms / 33ms / 大步长推进下事件轨迹完全一致。
- 禁止立即回退；无出口时消散并在间隔后重生，不出现零时间死循环。
- 共鸣石只影响正交四邻、不影响自身；乘算 0.75^n；间隔与冷却的硬下限生效。
- 联组：连续踩中成立、组外插入断链、超窗不成立、截止时刻含等号、跨脉流不拼接。
- 方位索敌只打本区域最近敌人，空区朝区域中心空射。

### 体验与流程（P2 起）

- 至少 3 名新玩家试玩，记录方向理解、摆位取舍、断链归因。
- 诊断面板用真实触发频率、闲置格、伤害来源、联组失败原因，不编造阈值。

### 性能（P4）

- 记录真实设备与浏览器；验收 Chromium 系与 Firefox。
- 150 敌人 + 300 弹丸 + 200 掉落压测 120 秒，60Hz 档帧间隔 p95 ≤ 20ms、p99 ≤ 33.3ms，无超过 250ms 冻结。
- 弹丸、掉落、伤害数字、临时特效池化；池满不覆盖活动攻击，记录饱和并调整上限。
- 连续五次重开后实体、监听器、队列回 baseline。

## 五、新增遭遇系统（规划，未实现）

- 沿途多个普通 NPC 遭遇，部分正式 Boss 在登场前固定出题；题目来自游戏内已提供的线索与规则。
- 答对直接消灭正式 Boss，答错进入真正 Boss 战。计时只开启遭遇，Boss 解决才结束本幕；最终 Boss 处决后直接胜利。
- 两条胜利路径共用基础奖励和进度结算，处决与奖励仅执行一次；处决时撤销 Boss 的待生成事件、召唤物和敌方在途攻击。
- 读题冻结全部战斗计时；选项打乱后仍按稳定 ID 判题；失败恢复要清空输入并先显示危险预警。
- 先做一个普通 NPC＋一个可实际战斗的基础 Boss，验证成功／失败双路径，再扩充多次事件。不做复杂 Boss 的范围控制不代表可以省略答错后的实际战斗。
- 新增验收：线索可解、普通事件答对／答错、Boss 问答处决／战斗胜利、最终结局、重复确认防重、暂停与后台恢复。题库与具体奖励惩罚数值仍待内容设计。
