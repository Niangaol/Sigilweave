# 美术素材包：清单、接线与回退

游戏里所有外部图片素材都在这页：56 张 png、被谁用掉、缺图时退化到什么，以及还没补的缺口。改立绘、加怪、换地砖前先看这里。

素材全部在 `public/assets/`，构建时随 Vite 拷进 `dist/assets/`；加载表在 [BootScene.js](<../src/scenes/BootScene.js>)。配色与描边的取舍理由见[画风同步设计规范](<素材加工/同步设计规范.md>)，资源目录与构建的关系见[技术架构](<技术架构.md>)。

## 一、清单

| 组 | 张数 | 文件 | 尺寸 |
| --- | --- | --- | --- |
| 精灵表 | 3 | `player_sheet` / `skeleton_sheet` / `corpse_sheet` | 768×56（12 帧 × 64×56） |
| 怪物单帧 | 28 | 敌种 id 同名图 + 5 张别名图 | 20×16 ~ 61×60 |
| Boss 立绘 | 14 | 场 1-7 各一张小 Boss + 一张场 Boss | 62×82 ~ 114×104 |
| 地砖 | 7 | `floor_act1..7` | 512×512 无缝 |
| 标题 | 2 | `title_wall`（480×270）、`hero_title`（146×176） | — |
| 特效 | 2 | `rune_shard`（10×10）、`attack_warning`（32×6） | — |

变体配件（盾 / 肩甲 / 王冠）**没有 PNG**，由 [variant-parts.js](<../src/ui/variant-parts.js>) 用 Graphics 烘焙成纹理。

## 二、每个素材用在哪

### 三张精灵表

| 素材 | 挂在 | 帧段（12 帧横排） |
| --- | --- | --- |
| `player_sheet` | `Player`，`FEET_OFFSET = 7` | 0-3 待机 / 4-6 行走 / 7 冲刺 / 8-11 受击 |
| `skeleton_sheet` | 骷髅兵（`ENEMY_ANIM.skeleton`） | 0-3 待机 / 4-7 行走 / 8-9 挥剑 / 10-11 倒地 |
| `corpse_sheet` | 腐尸（`ENEMY_ANIM.corpse`） | 0-3 待机 / 4-7 缓行 / 8-9 攻击 / 10-11 腐化 |

- 只有这两张怪表注册动画；其余单帧图只做朝向翻转。
- 主角立绘是**朝右**画的，所以 `flipXForPlayer(facing)` 是 `facing <= 0` 才翻。
- 立绘高 42px，法杖跟着上移：`staffTipOf` 的杖头在朝向侧 `+10 / -11`、尖端 `y-27`。所有法术特效从这点起手，改立绘就必须同步改它。

### 26 个敌种 → 立绘

19 个敌种的贴图键与 id 同名（`assets/sprites/<id>.png`），剩下 7 个走别名或精灵表：

| 敌种 | 用的图 | 备注 |
| --- | --- | --- |
| `skeleton` 骷髅兵 / `corpse` 腐尸 | 精灵表 | 唯一两个带动画的怪 |
| `bat` 噬魂飞行体 | `imp` | |
| `cultist` 邪教徒 | `skeleton_mage` | |
| `knight` 亡灵骑士 | `death_knight` | |
| `stitch_abomination` 缝合尸魁 | `ghoul` | 精英，`scale 1.15` |
| `oath_bishop` 咒誓主教 | `skeleton_mage` | 精英，`scale 1.2` + tint `0x9a86b8` |

脚底偏移在 `ENEMY_FEET`（6–9px，按各图画布底边对齐）；后四幕 4 种精英（`index_hound` / `scale_arbiter` / `anvil_tyrant` / `eclipse_priest`）统一放大 15%。

| 场 | 小 Boss | 场 Boss |
| --- | --- | --- |
| 1 荒废墓园 | `boss_gargoyle` | `boss_death_knight` |
| 2 腐沼教堂 | `boss_ghoul` | `boss_wraith` |
| 3 星陨王庭 | `boss_skeleton_mage` | `boss_void` |
| 4 沉钟书库 | `boss_library_mini` | `boss_library_final` |
| 5 衡律法庭 | `boss_court_mini` | `boss_court_final` |
| 6 熔星锻炉 | `boss_forge_mini` | `boss_forge_final` |
| 7 破晓之座 | `boss_dawn_mini` | `boss_dawn_final` |

立绘按场与 tier 选图，统一 `setDisplaySize(宽 × 目标高 / 高)` 缩到小 Boss 72px、场 Boss 104px，脚底对齐 `y+21`。[Boss.js](<../src/entities/Boss.js>) 另有 `minY = 42 + displayHeight - 21`，防止 104px 的立绘顶进 HUD。

### 场景级素材

| 素材 | 接线 | 用法 |
| --- | --- | --- |
| `floor_act1..7` | `Background.buildFloor` | `tileSprite` 铺满整个世界，`tileScale 0.5`、`alpha 0.65` |
| `title_wall` | `TitleScene.drawArtBackdrop` | 铺满 480×270，再压三层硬边暗带 |
| `hero_title` | 同上 | `(76, 258)`、`origin(0.5, 1)`、`scale 0.9`；提示文字随之从 `x=240` 左移到 `x=166` |
| `rune_shard` | `Shard` | 碎片本体；地面微光与高光仍走 Graphics |
| `attack_warning` | `Boss.draw` | 读条落点脚下横条，拉伸成 40×7 |
| `var_shield` / `var_pauldron` / `var_crown` | `variant-parts.js` | 重甲挂肩甲+盾、精英挂王冠；同名 PNG 一旦被预载就直接用图 |

## 三、加载与回退规则

`BootScene.preload` 只做两件事：`SPRITE_SHEETS` 3 张走 `load.spritesheet`（64×56），`SPRITE_IMAGES` 53 张走 `load.image`，合计 56。整个游戏没有第二处 `this.load.*`。

缺图不是崩，是逐层降级：

| 缺什么 | 谁降级 | 降级成什么 |
| --- | --- | --- |
| 精灵表 | `createAnims` | `textures.exists` 为假就跳过该动画；实体拿不到 `idle` 就不播 |
| 怪物单帧 | `Enemy` 构造 | `sprite` 保持 `null`，整体走程序化像素绘制；`viewExtent` 退回「逻辑半径 + 身体高度」估算 |
| Boss 立绘 | `Boss` 构造 | `sprite` 为 `null`，程序化画；`minY` 里的 `displayHeight` 记 0，不会因缺图把 Boss 顶出画面 |
| 本场地砖 | `Background.buildFloor` | 没有 `floor_act<N>` 就借 `floor_act1`/`floor_act3` 再染色：场 4 冷蓝 `0x9fb4d8`、场 5 银灰 `0xcfd6e0`、场 6 暖橙 `0xffb08a`、场 7 金白 `0xffd98a`；连借的图都没有才落回程序化石砖 |
| `title_wall` | `drawBackdrop` | 回退到程序化拱廊 + 月亮 + 石柱 |
| `hero_title` | 标题排版 | 提示文字回正到居中（`x=240`，`origin 0.5`） |
| 变体配件 | `ensureVariantTextures` + `Enemy` | 纹理生成失败就跳过，`parts` 保持空数组，怪照常出现只是没配件 |

规则只有一条：**素材缺失只影响观感、不影响逻辑**。所以判断一律走 `textures.exists`，不许「没加载就抛错」。

## 四、已知缺口

1. **5 张旧图还在预载清单里但已无实体引用**：`undead_bat`、`gargoyle`、`cultist`、`lesser_demon`、`lich`。`bat` 已改用 `imp`，`cultist` 已改用 `skeleton_mage`。
2. **地砖细节分两档**：`floor_act1..3` 每张 31–34 KB，`floor_act4..7` 只有 5.5–6 KB，后四场石板颗粒明显更轻。
3. **选包页 / 结算页的墙面叠加没做**，`title_wall` 目前只用在标题页。
4. **Boss 立绘靠重采样**：原图 62×82~114×104，一律缩到 72/104px，原图比例差得越多越糊。
5. **变体配件的 PNG 覆盖位留着但没有文件**：`assets/sprites/var_*.png` 不存在，三种配件全部走程序化烘焙。
