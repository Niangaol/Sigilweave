# 怪物重做 · 验收记录（2026-11-17）

> 起因（用户原话）：「感觉好神啊现在主角站着不动都不会掉血的 怪物的攻击到底怎么算的 给所有怪物大加强」，随后追加「给怪物加上一些招式 可以硬控角色」。
> 结论：不只是调数值——整条「攻击-伤害」链路是软的，重做了难度曲线、接触机制与硬控招式三层。

## 一、诊断（改动前）

站桩实测（60 秒不动、按真实刷怪节奏）：只挨打 21 次、总伤害 54、剩 46 血。密度仿真：第一场同屏峰值 9（上限 31）、60 秒只挨 1 点伤害，清场中位 2717ms。

四个叠加原因：
1. 接触伤害被压到 1~3（割草版为 60~90 只同屏主动下调）。
2. 无敌帧 1400ms 把掉血频率锁死在每 1.4 秒最多一次。
3. 普通怪碰到玩家就自毁，不会持续施压。
4. 怪物血量 4~12，法术随手清光，走到脸上的没几只。

## 二、改动（三层）

### 1. 难度曲线（`src/data/roster.js` 的 `DIFFICULTY` / `PLAYER`）

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 血量 | 4 → 12 | **14 → 42** |
| 移速 | 38 → 60 | **52 → 82** |
| 刷怪间隔 | 700 → 500ms | **440 → 380ms** |
| 同屏上限 | 34 → 66 | **52 → 88** |
| 兜底伤害 | 3 → 5 | **6 → 10** |
| 玩家无敌帧 | 1400ms | **660ms** |

### 2. 接触机制（`src/scenes/BattleScene.js`）

- 普通怪碰到玩家**不再自毁**，改为：命中 → 给玩家一次击退（36px）+ 240ms 僵直 → 该怪 600ms 接触冷却 → 被顶开 18px 继续追。
- 变体乘率同步上调：重甲 hpMul 1.60→1.90、damageMul 1.10→1.30；精英 hpMul 2.20→2.60、damageMul 1.35→1.60。
- Boss 血量与弹幕加厚：`BOSS_HP` base 130→170、perStage 65→85、majorMul 1.35→1.45；七套弹幕伤害 8/7/8/8/7/9/9 → 11/10/11/11/10/12/12。

### 3. 硬控招式（`src/data/control.js` + `src/entities/Player.js`）

| 类型 | 敌人 | 招式 | 控制 |
| --- | --- | --- | --- |
| 砸地 | 缝合尸魁 / 铁砧暴君 | 践踏 | 眩晕 700 / 900ms |
| 砸地 | 熔岩石像鬼 | 砸地 | 击退 110px + 240ms |
| 冲锋 | 亡灵骑士 / 黄铜守誓者 / 星屑骑士 | 冲撞 | 击退 100px + 240ms |
| 冲锋 | 索引猎犬 | 冲撞 | 击退 120px + 260ms |
| 扑咬 | 腐尸 / 符纹蛛 | 近战 | 定身 800 / 700ms |
| 远程精英 | 咒誓主教 / 日蚀祭司 / 水晶树妖 / 裁决幽魂 / 天平仲裁者 | 弹幕 | 迟滞（减速 35~50%，1.0~1.6 秒） |
| 远程 | 枷锁守卫 | 弹幕 | 定身 600ms |
| 接触 | 全部 | 身体碰撞 | 击退 36px + 240ms 僵直 |

玩家侧：`stunUntil` / `rootUntil` / `slowUntil` + `slowFactor`，眩晕与定身都会把移动输入归零（法术照常自动触发）；表现是头顶转圈星点（眩晕）、脚下冷色点圈（定身）、脚边紫线（迟滞），命中瞬间漂控制名。

## 三、验证

- 站桩仿真（`SIM_STAY=1 node scripts/density-sim.mjs`，不走位、不升级）：**47 秒阵亡**（改动前 180 秒仍剩 46 血）。
- 同屏峰值 22（上限 52），47 秒内击杀 42 只。
- 全量单测：`npx vitest run --config vitest.tmp.config.mjs --pool=threads` → **78 文件 / 1722 用例全绿**。
- 构建：`npx vite build --config vitest.tmp.config.mjs` → 成功。
- 文档一致性：`node scripts/check-docs.mjs` → 39 个文件引用齐全。

## 四、待实机确认

- 39 秒是「不动、不升级、不选卡」的极端值；真实玩家会走位 + 升级 + 联组，实际难度要低得多。
- 手感重点：击退 36px 与 600ms 接触冷却是否让「贴脸」变得太疼；精英眩晕 700/900ms 是否太长。
- 远程弹幕目前统一迟滞（不带来源 defId），精英专属的击退/定身留给带来源信息的版本。
