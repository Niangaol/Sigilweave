# 法术特效 v2 验收（大胆版，2026-11-09）

> 用户诉求原话：「为游戏里的各种法术增加独特的动画，效果明显、设计大胆、区分度高」。
> 结论：16 个法术全部重做，视觉体积相比 v1 放大约 2.5 倍，一法术一个专属动作；
> 895 项单测全绿、vite build 通过、真实浏览器实机截图 34 张、帧时间 p95 4.6ms。

## 一、动工前的诊断（为什么 v1 不行）

v1 的 src/ui/spell-fx.js 已经有 16 套特效，但实机截图 docs/mow-fx/10-法术总览-命中.png 里几乎看不见：

| 项 | v1 实测 |
| --- | --- |
| 笔画 | 1.0~1.4px 细线 |
| 弹体 | 3~7px 小菱形 |
| 命中图案 | 0.5~0.9R（寒霜只有约 30px） |
| 形状语言 | 16 个法术共用「环 + 菱形 + 点」，只靠换颜色 |

结论：区分度低的根因不是配色，是共用同一套几何语言。所以 v2 不是「调颜色」，是换掉整套画法。

## 二、架构（可并行开发的拆分）

接线处（Projectile / EffectsLayer / BattleScene）不需要关心实现文件，继续 import ./spell-fx.js 即可。

## 三、四条硬纪律（测试在守）

1. 只用 fillStyle + fillPoints / fillRect；禁止渐变、模糊、lineStyle、Math.random。
2. 所有顶点整数像素（kit 自动取整）。
3. alpha 在 [0,1]。
4. 确定性：抖动只用 hash01；clock 只改相位，不改绘制调用数量。

## 四、尺寸口径（v2 的两道收口）

原来命中图案直接吃「伤害半径」，而伤害半径从 18（寒霜）到 95（陨星）差 5 倍，于是寒霜 30px、陨星 400px。

- visualRadius：(30 + 0.35 × R) × 0.8 —— 把小法术抬起来、大法术压住；0.8 是实机镜头（约 4 倍像素放大）的观感校正。
- IMPACT_SCALE：每法术 0.46~0.6，保留轻/重差异。

结果：16 个命中图案最大边 55~140 世界像素（480px 战场宽的 11%~29%），轻法术不再消失，重击也不会糊住半屏。

## 六、命中重量（新反馈层）

| 档位 | 法术 | 震屏 | 顿帧 | 同法术去重 |
| --- | --- | --- | --- | --- |
| 轻 | 寒霜/飞弹/闪电/回声/汲取 | 0.0022~0.003 | 无 | 70~90ms |
| 中 | 烈焰/余烬/荆棘/噬魂/守护 | 0.0026~0.0038 | 无 | 110~200ms |
| 重 | 贯穿/星陨/裁决/地裂/陨星 | 0.0042~0.009 | 35~75ms | 140~260ms |

- 顿帧只冻结战斗推进（引擎/敌人/弹丸），HUD 与画面照常，不会拖慢割草节奏。
- 同一法术 gapMs 内只吃一次震屏，避免齐射 3 发叠成连续抖动。
- 特效寿命也按重量分档：轻 380~420ms、中 520~640ms、重 760~980ms。

## 八、已知取舍（不装懂）

1. 敌人命中白闪：Enemy.setTintFill(0xffffff) 是既有打击反馈，密集击杀时会叠出一团白色剪影；
   陨星命中截图里那团「白烟」就是它，不是本轮特效。要改需要动敌人渲染，不在本轮范围。
2. 测试口径调整：visualRadius 上线后，tests/spell-fx.test.js 里 quake_maw 牙数、pierce_lance 跨度
   两条断言从「按伤害半径」改成「按绘制半径」。这是架构变更的必要同步，不是放宽标准：
   相对关系（牙数随半径加密、跨度 > 2.5 倍绘制半径）仍然被钉死。
3. 500ms 内同屏多枚重击：顿帧取 max 而不是叠加，最多 75ms；观感优先，牺牲一点「连环砸」的极端表现。

## 十、补充轮（2026-11-09 晚）：出现 / 消失细节 + 两个高级法术的夸张演出

### 1. 所有法术都补上了「出现」与「消失」

原来 16 个法术的命中图案是「瞬间满尺寸 + 线性淡出」，等于没有出现也没有消失。现在分三层：

| 层 | 做什么 | 位置 |
| --- | --- | --- |
| 时间包络 | 命中前 13% 主体从 50% 尺寸弹到 100%（smoothstep）；72% 之后主体 k 加速 1.9 倍，先散架 | src/ui/spell-fx/index.js |
| 入场层 | 三类语言：converge 光点向心凝聚 / erupt 亮环炸开 / assemble 符文块从外归位 | kit.js drawEntry |
| 退场层 | 三类语言：dissipate 残余光点被吸回中心 / settle 碎屑外飘上浮+残环焦痕 / shatter 环带碎裂飞散 | kit.js drawExit |

另外弹丸在飞行最初 8% 有「出膛凝形」小闪环（drawSpawnFlash），护盾的环会先收拢再展开、散场时碎裂。
分组：弹道类 7 个走 converge/dissipate、爆裂与地面类 7 个走 erupt/settle、守护类 2 个走 assemble/shatter。

### 2. 陨星裁决 / 地裂之颚 的夸张演出

新增 src/ui/strike-fx.js（纯绘制，独立于 spell-fx），两套 1.4~1.6 秒的多段演出：

| 法术 | 时长 | 分段 |
| --- | --- | --- |
| 陨星裁决 | 1600ms | 冲击白热核心（0~8%）→ 双道贴地冲击波（8~35%）→ 尘柱上升（20~60%）→ 抛射碎石（35~75%）→ 二次余震+裂缝蔓延（55~95%）→ 焦痕余韵（80~100%） |
| 地裂之颚 | 1400ms | 横向白热裂缝（0~6%）→ 裂口张开+岩层翘起（6~30%）→ 裂纹蔓延（25~60%）→ 塌落碎石（30~70%）→ 二次开合（60~85%）→ 暗腔余韵（85~100%） |

屏幕级配套（BattleScene.spellStrikeSequence）：
- 震屏升级到 0.010~0.012（普通重击是 0.0042~0.009），顿帧 90~110ms（普通重击 35~75ms）
- 陨星额外一帧相机白闪（80ms），两者都带暗角脉冲（EffectsLayer.vignette，四边压暗再回弹）
- 这两个法术不再叠加普通 punch，避免震屏被触发两次
