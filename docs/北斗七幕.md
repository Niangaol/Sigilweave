## 4. 美术说明（2026-11-11 补做，对齐前三幕）

- **8 张专属 Boss 立绘**：每幕小 Boss / 大 Boss 各一张，统一 72 / 104px 显示档、透明底、≤32 色。做法是沿用现有立绘的像素语言与明暗骨架，重新上色并叠加本幕专属头饰与武器（书吏宽檐帽与羽笔、万卷之喉的巨书口与竖瞳、铁面陪审的铁面具与法槌、失衡法官的断秤、淬火傀儡的炉门、熔心匠主的熔心与巨锤、残星骑士的七星星钉盾、破晓之王的七枚星屑王冠与晨光披风）。
- **12 种专属敌人**（每幕 2 普通 + 1 精英）：墨灵 / 纸页傀儡 / 索引猎犬；判词幽灵 / 枷锁守卫 / 天平裁决者；炉渣兽 / 火星精 / 铁砧暴君；晓色之影 / 星屑骑士 / 蚀日祭司。全部有独立 PNG，尺寸 36-60px，透明底、≤32 色，并统一补了轮廓光与底部压暗。
- **4 张 512×512 无缝地板**：沉钟书库（深蓝石板 + 铜金书纹）、衡律法庭（冷银石板 + 天平刻纹）、熔星锻炉（铁板 + 铆钉 + 橙红熔线）、破晓之座（深紫石板 + 金白星纹）。Background 优先用本幕专属地板，缺图才回退旧地板染色。
- **4 种新精英行为**：索引猎犬 700ms 蓄力后 4.2 倍速扑咬；天平裁决者 130px 外蓄力打慢速重弹；铁砧暴君贴近后 650ms 蓄力砸出 46px 震荡；蚀日祭司蓄力后打八向星环。
- 开场「七契钉入」与结局「七契尽解」仍用同一组圣物形状，数量从 3 改为 7。

- `npm test`：**47 个测试文件、1064 项全绿**（含七幕断言与四种新精英行为测试；工作区另有一组未跟踪的 `editor-ui` 测试也计入，非本次改动）。

## 7. 已知边界

- 八张 Boss 立绘是在现有立绘明暗骨架上重绘配色与道具的专属立绘，不是全新 AI 原画；12 种敌人与四张地板是程序化像素绘制，细节密度略低于前三幕的 AI 原画，但尺寸、描边、色数与显示档完全对齐。
- 后四幕场景是程序化主题变体，与前三幕共用石砖/噪点/结界/蜡烛骨架。
- 平衡数值（间隔、密度、Boss 等级）是延续现有曲线的推定值，尚未经过人类试玩；如需调整，唯一来源分别是 `constants.ACTS`、`roster.ACT_DENSITY`、`progression.MAJOR_BOSS_LEVEL`。
