# 法术的第三层身份：形态、派系、进化与连携

> 24 张符印除「伤害 + 方位」之外还有五层身份：锐 / 谐形态、七派系共鸣、四类反应、进化路线、专属连携。全是数据驱动的附加层，不改符印本体的 `kind` / `radius` / `cd`。
> 数据在 `src/data/` 的 `variants.js` / `factions.js` / `evolutions.js` / `linkages.js`，判定在 `src/logic/resonance.js`、`linkage.js`（经 `effects.resolveSigilTrigger` 追加），表现在 `src/ui/spell-fx/`、`spell-punch.js`。
> 数据表见[内容规格表](<内容规格表.md>)七·五，联组见[规则契约](<规则契约.md>)§4。

## 一、五层身份

| 层 | 规模 | 什么时候生效 |
| --- | --- | --- |
| 形态 | 20 张三形态，4 张强力法术只有 `base` | 抽卡时 roll 一次，写进槽位 |
| 派系 | 7 个，24 张各属一个 | 同派系**相邻**格给伤害加成 |
| 反应 | 4 类（融化 / 导电 / 灼烧 / 净化） | 该格相邻出现指定两派系时，触发后追加一段 |
| 进化 | 24 个符印 × 2 路线 = 48 条 | 升级三选一里出现，选中后该法术**所有**格子一起升级 |
| 连携 | 10 对指定配对 | 配对的两格在同一联组里时追加一笔 |

## 二、口径

- **形态**：权重 `0.45 / 0.275 / 0.275`，伤害倍率 `1 / 1.3 / 0.82`。`harmon`（谐）伤害 −18% 换联组资格；`starfall` / `meteor_judgment` / `quake_maw` / `judgment_hammer` 在 `COMBO_LOCKED` 里，只有基础形态、不参与联组。
- **共鸣**：同派系相邻格每个 `+10%`，上限 `+30%`（`RESONANCE_STEP` / `RESONANCE_CAP`），与加成杖、增益乘算。
- **反应**（同一格 2 秒最多一次，`REACTION_COOLDOWN_MS`，存在 `cell.reactionUntil`；脉流跳格很频繁，不冷却会每跳刷一次）：

| 反应 | 触发组合 | 效果 |
| --- | --- | --- |
| 融化 | 冰 + 火 | 目标易伤 1.15×，持续 2000ms |
| 导电 | 雷 + 冰 | 目标冻结 1200ms，并对最近的另一只怪补一跳 0.3× |
| 灼烧 | 火 + 野性 | 按命中目标数追加 0.9× 总量、切 3 跳 |
| 净化 | 魂 + 圣 | 亡灵 / 腐化目标额外 1.4×，玩家回 2 血 |

- **进化**：`rollEvolutionPick` 只从「已拥有且未升级」的符印里挑，45% 概率出现、只占三选一里的 1 张；无可用路线返回 `null`，其余位置由普通卡补满。
- **前摇**：只有 5 张有 `castMs`——霜华新星 600、雷霆风暴 400、日轮耀斑 700、荆棘巨槌 350、冰川裂谷 450ms。先落预警圈，`engine.now` 到点才结算；暂停 / 顿帧时时钟不走，前摇自然停住。
- **连携**：10 对、`bonus` 0.35~0.5，同一对 1.5 秒冷却；反应与连携互不占用对方的随机流。

## 三、验收证据

11-16 实拍：`scripts/fx-preview.mjs` 出的拼版（`mow-fx-preview.png` 与同名目录下逐法术图），确认 24 套特效剪影可区分、锐 / 谐只改配色不改几何结构。

自动化：`tests/variants.test.js`（权重、倍率、`COMBO_LOCKED` 四张）、`tests/factions.test.js`（七派系、四反应参数）、`tests/evolutions.test.js`（48 条、每符印 2 条）、`tests/linkage.test.js`（10 对、冷却与 `bonus`）、`tests/new-sigils.test.js`、`tests/spell-fx.test.js`。全量 **86 files / 1774 tests** 全绿。

## 四、已知边界

1. 反应有 2 秒同格冷却，脉流全开时反应贡献被压住——不让跳格把反应刷成主伤害来源。
2. 进化靠 45% roll、不进保底，一局见不到某路线是常态。
3. 连携要求两格在同一联组内，摆放顺序与形状决定吃不吃得到，不是纯数值加成。
4. 谐律 −18% 是明码交换：少伤害、换「第一波就能摆联组」。
5. 特效层只用 `fillStyle` + 取整顶点 + `hash01(seed)` 抖动，同一法术不同 `clock` 的绘制调用数必须相同。
