# 共振法阵 · 内容规格表

> 这张表回答一个问题：游戏里到底有什么，每样东西的数值是多少。
> 卡牌、法术形态、派系、进化、连携、敌人、职业、被动、遭遇题、经济，一类一张表；数值逐项抄自 `src/data/*.js` 与 `src/logic/*.js`，不换算、不四舍五入。
> 规则怎么生效看 [规则契约](<规则契约.md>)，幕和场怎么排看 [五幕七场](<五幕七场.md>)。

| # | defId | 名称 | 格数 | 判定 | 追加伤害 |
| --- | --- | --- | --- | --- | --- |

| 2 | `line3` | 直线三连 | 3 | 同行或同列三格依次踩中 | **只有末格**追加 40% |

- 形状按相对行列定义，8 种二面体变换 + 反向都算，4×4 内全部有序实例由 `concreteInstances` 生成（`src/logic/combo.js`）。

- 联组资格看变体：只有谐律（`combo: true`）能进联组，标准与锐都不能（§7.1）。

### 8.3 护甲与破盾

- **只有重甲变体有甲**：`shieldHp = round(最终出生生命 × 0.6)`。最终生命 = 难度基准 × 等级成长 × 敌种 `hpMul` × 变体 `hpMul` 之后再取整，不是基础表里的数字。
- 结算固定顺序「盾 → 甲 → 血」，唯一入口 `effects.applyDamage(enemy, amount)`。返回值只统计扣血部分，被盾吸收的不计入。
- 甲是一次性的、不回复、不随幕重算；`shield` 缺省/非有限/≤0 时完全走无盾路径。
- 破盾：`applyDamage` 只置 `shieldBrokenPending`，`Enemy.update` 消费一次 —— 盾归零、`stunUntil = now + 400`、隐藏肩甲与盾两件配件。眩晕期间位置冻结、不产弹丸、不冲锋、`damage` 回基础值。
- 破盾表现：4 块菱形碎片 400ms + 两声下坠音 + `shake(120, 0.002)`；护甲值吸收时只播青钢色火花与 `sfx.shieldHit()`，飘字只按实际扣血走；`shield > 0` 时血条上方 3px 画 13×1 暗底 + 11×1 青钢条。
- 尸爆也走同一个 `applyDamage`，所以会被盾吸收——这是有意的，让「更耐打」的重甲在连锁里保持一致的生存手感。盾不区分伤害类型，不引入元素抗性。
- `armor` 只属于格挡：`guard` 为真时 `armor = 0.55`（纸页傀儡 `bulwark` 举盾），非格挡状态下敌人 `armor` 恒为 0。盾减伤与格挡减伤互不叠加。

- 玩家控制状态在 `src/entities/Player.js`：`stunUntil` / `rootUntil` / `slowUntil` + `slowFactor`；眩晕与定身都会把移动输入归零，法术照常自动触发。
- 反制（2026-11-18 反硬控）：右键冲刺可解定身 / 迟滞 / 击退僵直（`startDash` 启动即清 `rootUntil` / `slowUntil` / `knockStunUntil`），眩晕解不掉；冲刺 180ms 位移 108px + 220ms 无敌，冷却 1200ms、后摇 400ms，同种控制短时间内反复命中会按 1→0.6→0.35 抗性打折（`CONTROL_RESISTANCE`，单次不低于 150ms）。
- 敌人抬手前摇统一推红色预警环（`Enemy.windupAt` / `windupDur`，时长取 `MELEE_RULES` / `RANGED_RULES` 的 `windupMs`；两张表都没有的敌种不推环），给玩家提前躲的反应窗口。
- 表现：眩晕 = 头顶三颗转圈星点；定身 = 脚下一圈冷色点；迟滞 = 脚边一道紫线；命中瞬间漂「眩晕 / 定身 / 击退 / 迟滞」字样。
- 远程弹幕目前不带来源 defId，全场统一挂 `DEFAULT_SHOT_CONTROL`（减速 30%、900ms），精英的专属配置留给带来源信息的版本。

### 编队（2026-11-18 波 C）

刷怪不再每轮只 roll 单个敌种：每 `DIFFICULTY.formationEvery = 3` 轮，且幕内抽得到模板时，整队一起刷出来，并走同一个 `formationId`。

| 编队 | 名 | 幕 / 权重 | 成员（职能 × 只数） | 光环 |
| --- | --- | --- | --- | --- |
| `siege` | 远程阵地 | 2+ / 3 | 前排 石像鬼·纸页傀儡 ×1 · 远程（水晶树妖/判词幽灵/虚空符灵）×3 | 有 |
| `shield_wall` | 盾墙推进 | 3+ / 3 | 前排 纸页傀儡 或 黄铜守誓者 ×1 · 远程 ×2 | 有 |
| `pincer` | 钳形夹击 | 3+ / 3 | 前排 亡灵骑士·星屑骑士 ×2 · 控制（邪教徒/枷锁守卫）×1 | 有 |
| `mixed` | 混编 | 4+ / 2 | 前排 ×1 · 远程 ×1 · 控制 ×1 · 游击 ×1 | 有 |
| `harass` | 骚扰 | 2+ / 4 | 游击（蝠/火星精/符纹蛛/幽魂）×3 · 远程 ×2 | 无 |
| `brute` | 重压 | 2+ / 3 | 精英（黄铜守誓者/铁砧暴君/缝合尸魁）×1 · 杂兵 ×2 | 无 |
| `casters` | 双法 | 3+ / 2 | 精英（咒誓主教/蚀日祭司）×2 · 杂兵 ×2 | 无 |
| `swarm` | 蝠群 | 1+ / 4 | 蝠 ×5 · 符纹蛛 ×1 | 无 |

光环固定一条：**前排存活时，同批其余成员 +15% 护甲（`armorBonus`，与自身护甲相加后夹在 0..1）与 ×0.9 移速（`speedMul`）**。移速是减速不是加速——编队是「一堵会动的墙」，比散兵慢但更硬。

- **前排判定**：走 `vanguard` 职能的成员（含精英）活着 → 同**批**其余成员拿光环；前排自己不拿、精英收方一律不拿（`精英不参与编队光环`讲的是收方）。
- **分组按批不按模板**：`formationId` 是模板（取光环数值、取标记色相），`formationUid`（`模板#序号`）才是这一批的分组键。同模板两批同屏时是两支独立的队：A 队前排死了，B 队前排不替它发光环。
- **标记**：同批成员脚下画同色小三角（4 色轮转，按 `formationUid` 哈希）。前排精英也画——否则 `shield_wall` 在第 3/5 幕会出现「光环来自唯一没有标记的那只」。首次见到时触发引导 G19。
- **降级**：本幕抽不到模板、或总员额超出剩余槽位时，整轮退回普通波，不硬塞。第 4 幕 `swarm`、第 5 幕 `swarm`/`pincer`/`mixed` 常年不在怪池，属预期的降级。
- **不吃光环**：Boss、精英收方；召唤物（炮台/符文）不在编队桶里。

### Boss 三阶段（2026-11-18 波 B）

一场 Boss 战按血量分三段，阶段推进是「一次一档」，转阶段时有 0.9 秒不推进的演出窗口（`PHASE_SHIFT_MS`）。

| 项 | 一段 | 二段 | 三段 |
| --- | --- | --- | --- |
| 推进阈值 | 100%→66% | 66%→33% | 33%→0（含 20% 狂暴） |
| 抬手 | 600ms | 540ms | 480ms |
| 弹数 | ×1 | ×1.25 | ×1.5 |
| 出手间隔 | ×1 | ×0.82 | ×0.68 |
| 移速 | ×1 | ×1.08 | ×1.15 |
| 大招间隔 | 12s | 10s | 8s |

- **首招提前**：进入战斗后第一次大招在 4 秒 + 1.2 秒蓄力后落地（`min(4000, ultEveryMs)`），之后按上表的阶段间隔循环。不这么改时 12 秒间隔的场次从头到尾见不到一次大招。
- **大招**：每场一套专属弹幕（`BOSS_ULTIMATES`），落地后 **1.2 秒破防**（`BREAK_WINDOW_MS`）：此时 Boss 护甲归零、受到伤害 ×1.2（`BREAK_DAMAGE_MUL`），是玩家的爆发窗口。
- **狂暴**：血量降到 20% 以下时出手间隔乘 0.8（`ENRAGE_ATTACK_MUL`），可重叠在大招破防上。
- **转阶段**：震屏走 `SHAKE_KINDS.phase`（`hurt` 有 900ms 节流，连用会被吞），清掉 Boss 自己的弹丸但**保留它刚打出来的大招弹幕**（`fromBoss` 标记区分）。
- **大招弹带来源**：只有大招的弹丸带 `fromBoss`，命中时按本场的 `BOSS_CONTROLS` 施加控制，普通阶段弹仍走 `DEFAULT_SHOT_CONTROL`。七场里前两场大招不带控制（`null`，纯弹幕压力），三/四场迟滞（1000ms×0.6 / 1200ms×0.55）、五场定身 800ms、六场击退 90px + 240ms、七场眩晕 700ms。
