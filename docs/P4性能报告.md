# P4 性能与生命周期验证

> 环境：Windows 10/11 + 系统 Edge（Playwright channel=msedge），headless 软件渲染，960×540 视口，480×270 逻辑画布。
> 口径：软件渲染的绝对值偏悲观，本报告用于防冻结与回归比较，不代表真机上限。

## 压测场景

通过 `?stress=1` 显式启用（正常玩法不加载）：真实实体类填充到 **150 敌人 / 约 300 弹丸 / 200 碎片**，持续 20 秒并每 250ms 补满，采样相邻 requestAnimationFrame 间隔（丢弃前 2 帧）。

脚本：[scripts/stress.mjs](<../scripts/stress.mjs>)

## 结果（2025-10-23 实测）

| 指标 | 实测 | 计划验收线 | 结论 |
| --- | --- | --- | --- |
| 采样帧数 | 5854 | — | 有效样本充足 |
| p50 | 3.3 ms | — | — |
| p95 | 4.4 ms | ≤ 20 ms | 通过 |
| p99 | 6.6 ms | ≤ 33.3 ms | 通过 |
| 最大帧间隔 | 56.7 ms | 无 > 250 ms 冻结 | 通过 |
| 压测末实体数 | 150 敌 / 294 弹丸 / 203 碎片 / 684 显示对象 | — | 堆叠目标达成 |

多次重跑 p95 稳定在 4.2–4.4 ms，最大帧 35–80 ms 波动，均远低于 250 ms 冻结线。

## 生命周期

连续重开 5 次，每次等待新一次 boot（启动计数递增）后采样：

| 次数 | 敌 | 弹丸 | 碎片 | 显示对象 |
| --- | --- | --- | --- | --- |
| 1–5 | 0 | 1（引擎自然产生的在途弹丸） | 0 | 36 |

数组、显示对象、计时器均回到基线，无累积泄漏；浏览器 pageerror 全程为零。

## 本轮顺带修复

- 场景重开后调试句柄不恢复：shutdown 置 null 后，create 里 `=== undefined` 判断不再赋值，导致重开后的验收句柄失效。已改为每次 create 无条件赋值并加启动计数。
- 静默铭文语义写反（原来把邻格冷却清零、变成加速）：已改为压制邻格、迫使其走完整冷却。
- 敌人死亡直接 splice 绕过 onEnemyKilled，Boss 非弹丸死亡无法通幕：已统一汇入 defeatBoss。
- 幕间页签导入路径错误导致构建失败：已修正。

## 本轮同时交付

- **出口编辑**：幕间可逐格开关上下左右出口，出发后真实影响脉流路由；浏览器回归验证移除“右”后战斗内出口集合为 up/down/left。
- **联组断链诊断**：引擎新增 combo:break 事件与按原因统计（冷却受阻／保底改道／脉流消散），战斗中浮字提示，上幕报告带 comboBreaks 明细。
- **合成音效**：无外部素材的 WebAudio 短音，覆盖触发、吞跳、联组、消散、受击、拾取、问答、Boss 陨落；M 键静音。
- 修复压测暴露的调试句柄不恢复，与 keydown-M 注册过早导致场景创建失败两处缺陷。

## 跨浏览器验证

- 安装 Playwright Firefox 后，对**线上 GitHub Pages** 跑了布局回归与三幕通关回归：地图走位、暂停恢复、6/12/16 格、1/1/2 脉流、三位 Boss 问答消灭、最终「契约终结」结算全部通过，pageerror 为零。
- 脚本支持 `BROWSER=firefox` 切换通道：`BROWSER=firefox BASE_URL=https://niangaol.github.io/Sigilweave node scripts/three-act-smoke.mjs`。
- 仍**未**在真实 GPU 桌面环境复测；性能数字只在 headless Edge 软件渲染下采集。
