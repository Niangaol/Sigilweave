# 法术特效 v2 设计规格（大胆版）

> 2026-11-09。目标一句话：**在 60 怪混战里，只看剪影就能认出是哪个法术。**
> v1 的问题是 16 个法术共用「1px 细线 + 菱形 + 小点」的几何语言，只靠换颜色，实战中全部糊成一团。

## 一、四条硬纪律（测试会守）

1. **硬边像素**：只用 fillStyle + fillPoints / fillRect。禁止渐变、禁止模糊、禁止 Math.random。
2. **顶点取整**：所有顶点必须是整数像素（kit 的 poly/dots/blocks 已自动取整）。
3. **alpha 在 [0,1]**，整体随 k 单调不增（峰值闪只用 peak(k,0.15) 这类有界曲线）。
4. **确定性**：抖动只用 hash01(seed)；clock 只能改相位，不能改绘图结构（同一法术不同 clock 的绘制调用数必须相同）。

## 二、尺寸口径（v1 → v2）

| 通道 | v1 | v2 |
| --- | --- | --- |
| 弹体主体 | 3~7px | **10~16px**（体积三层） |
| 描边 | 1.0~1.4px 线 | **2.6~4px 环带 / 3px 外扩轮廓** |
| 命中图案 | 0.5~0.9R | **1.6~2.2R**，且必须有实心连续多边形 |
| 拖尾 | 2px 点阵 | **锥形实体丝带**（尾 1.6px → 头 6~9px）+ 元素花活 |
| 护盾环带 | 1.4px | **3~4.5px 环带** + 符文块 |

## 四、通用时间包络

- **起手 cast（320ms）**：预警环由小到大 + 元素成形（不能只是「一个环」）。
- **命中 impact（260~420ms）**：
  - k < 0.15：全尺寸最亮（peak），中心 4~6px 白闪，这是「打到了」的读感来源；
  - k 0.15~0.6：图案继续外扩、亮度回落；
  - k > 0.6：余韵（焦痕/碎屑/残环），alpha 0.2~0.4 但不为 0。
- **护盾 ward（640ms）**：环带 + 符文块绕轴转。
- **连接 link（240ms）**：粗丝带 + 流向节拍块。

## 五、绘制预算（v2 新契约）

单次调用的绘制指令数（fillStyle + fillPoints/fillRect 各计 1）上限：

| 通道 | v1 上限 | v2 上限 |
| --- | --- | --- |
| projectile | 40 | **72** |
| trail | 30 | **52** |
| cast | 30 | **64** |
| impact | 80 | **140** |
| ward | 80 | **140** |
| link | 30 | **52** |

opBudget（每法术自己的最大值）用 node scripts/fx-budget.mjs 实测后回填。
性能口径：最坏情况（6 个 impact + 9 个 projectile + 9 条拖尾同帧）总指令数 < 2600。

## 六、kit.js API 速查

kit 路径：src/ui/spell-fx/kit.js

- poly(g, pts, color, alpha) —— 一个实心多边形（<3 点自动跳过）
- shell(g, build, col, a) —— build(scale) 画成 暗轮廓/本体/亮芯 三层（体积感主力）
- band3(g, pts, w0, w1, col, a) —— 锥形粗折线，含三层
- ring3(g, cx, cy, rad, w, col, a, {phase, squash, seg}) —— 粗环带三层
- sectorPts / spikePts / blobPts / boltPts / starPts / hexPts / arrowPts —— 返回顶点，交给 poly/shell
- drawTrail(g, c, col, { max, farW, nearW, style, sway, driftX, driftY }) —— 锥形丝带 + 花活
- peak(k,0.15) 命中峰值闪；fade(k)=1-k；pulse(clock,ms) 呼吸相位；hash01/hashSym 确定性抖动

## 八、实施后的修订（2026-11-09 收尾）

设计与实现有四处出入，以本节为准：

1. **尺寸不再直接吃伤害半径**。伤害半径 18（寒霜）~95（陨星）差 5 倍，直接用会出现「小法术 30px、大法术 400px」。
   现在门面统一收口：visualRadius(R) = (30 + 0.35R) × 0.8，再乘每法术的 IMPACT_SCALE（0.46~0.6）。
   最终 16 个命中图案最大边落在 55~140 世界像素。
2. **护盾环额外收 15%**：它常驻在玩家身上，太大容易糊住角色。
3. **命中重量表独立成模块** src/ui/spell-punch.js：震屏 / 顿帧 / 同法术去重间隔，BattleScene 只调 spellPunch()。
4. **特效寿命按重量分档**（EffectsLayer.IMPACT_DUR）：轻 380~420ms、中 520~640ms、重 760~980ms。

新增的可复跑工具：
- node scripts/fx-check.mjs src/ui/spell-fx/spells/<组>.js —— 逐法术预算/整数顶点/alpha/确定性/样式名
- node scripts/fx-extent.mjs —— 命中图案实际像素尺寸（防止越画越大）
- node scripts/fx-phases.mjs [输出目录] —— 每法术命中 4 相位时序图

五、预算表未变：projectile 72 / trail 52 / cast 64 / impact 140 / ward 140 / link 52。
