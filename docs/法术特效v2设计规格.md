# 法术特效规格

24 张符印各自的绘制规格：每张在六个通道里各有一套图案，共用一条管线。目标：60 怪混战里只看剪影就能认出法术。

实现：`src/ui/spell-fx/`（`kit.js` 笔刷 + `spells/` 五组 + `index.js` 分派），`src/ui/spell-fx.js` 只转发。

## 一、六类绘制

| 通道 | 入口 | 触发 | 寿命 | 画什么 |
| --- | --- | --- | --- | --- |
| 飞行体 | `drawProjectileFx` | `Projectile.draw` | 飞行期 | 主体体积，`k` 是弹道进度 |
| 拖尾 | `drawTrailFx` | 同上 | 同上 | 锥形丝带 + 花活，点数上限 `trail.max` 5~8 |
| 起手 | `drawCastFx` | 每次开火 | 320ms | 法杖尖端成形爆发 |
| 命中 | `drawImpactFx` | `commitSigil` | 380~980ms | 招牌图案 |
| 护盾 | `drawWardFx` | 三张 ward | 640ms | 玩家的环带 / 盾面 |
| 连接线 | `drawLinkFx` | 连锁 / 贯穿 / 回声 / 噬魂 / 汲取 | 240ms | 两端粗丝带 |

命中半径 = `visualRadius(伤害半径) × IMPACT_SCALE[defId]`；未知 id 落 `FALLBACK_FX`（菱形 + 高光），六个函数都不空。

## 二、出现与消失

`entryRadius` 在前 13%（`ENTRY_SPAN`）把半径从 50% 弹到 100%；`exitK` 在 72%（`EXIT_START`）后把主体 `k` 加速到 1.9 倍，再让碎片层收尾。命中与护盾再叠一层入退场，分三类：

- 弹道 `converge` / `dissipate`（9）：寒霜箭、奥术飞弹、连锁闪电、穿刺之矛、回声符文、秘能汲取、噬魂箭、虚空之矛、魂灵回声
- 爆裂 `erupt` / `settle`（12）：其余爆裂与范围法术
- 守护 `assemble` / `shatter`（3）：圣光壁垒、圣环、圣所

飞行体另有出膛凝形（`drawSpawnFlash`，5 → 12px），入退场层各最多 40 条指令。

## 三、尺寸与颜色

`visualRadius(R) = (30 + 0.35R) × 0.8`：R=18 → 29.0px、46 → 36.9px、95 → 50.6px，轻 / 重留约 2 倍差，再乘 `IMPACT_SCALE`（0.46~0.6），护盾额外收 15%。实测命中图案最大边 32~142px（虚空之矛 52×32，陨星 142×102）。

四色：`edge` 暗轮廓、`body` 主色、`core` 亮芯、`accent` 点缀；24 个 `body` 两两不同，弹体、命中、护盾、罗盘格闪光共用。

## 四、与 `spell-punch.js` 的分工

`spell-fx` 只画图案；「打到有多重」全在 `src/ui/spell-punch.js`，`BattleScene` 只调 `spellPunch()`。

- 轻 5 张：70~90ms / 0.0022~0.003，不顿帧。
- 中 8 张：90~110ms / 0.0026~0.0038，不顿帧。
- 重 11 张：120~280ms / 0.004~0.009，除霜华新星外顿帧 35~75ms。
- 演出只有两张：陨星 340ms / 0.012 / 顿 110ms、地颚 280ms / 0.010 / 顿 90ms，走 `strike-fx` 多段演出。

同一法术 `gapMs`（70~260ms）内只吃一次震屏，否则一刀扫 3 只会叠抖。

## 五、绘制预算

单次调用的绘制指令数（`fillStyle` + `fillPoints` / `fillRect` 各计 1）上限 / 实测最大：飞行体 72 / 47、拖尾 52 / 20、起手 88 / 56、命中 176 / 138（陨星）、护盾 160 / 124（圣光壁垒）、连接线 52 / 19。

`opBudget` 是法术自己图案的上限，门面再叠入场 / 退场，测试给 40 条（`CHROME_BUDGET`）余量。最坏帧（6 命中 + 9 弹体 + 9 拖尾）实测 937，线 2600。

## 七、验收

- `tests/spell-fx.test.js` 23 条：24 × 6 = 144 次调用都有绘制、逐通道不超上限、`k=0/1` 两端不炸、顶点整数、alpha 在 [0,1]、`clock` 只改相位、几何签名 24 个两两不同。11-16 实测全绿。
- `node scripts/fx-preview.mjs` 出 24 张到 `docs/mow-fx-preview/`，每格摆六个通道；联系表 4×4 只排前 16 张，全 24 张开目录。
- 实机：`node scripts/mow-fx-shot.mjs` 出 `docs/mow-fx/`（飞行 / 命中各 16 张，11-16 实拍）、`docs/mow-fx-phase/`、`docs/mow-fx-strike/`。
- 自检：`node scripts/fx-check.mjs src/ui/spell-fx/spells/fourth.js`（预算 / 顶点 / alpha / 样式名）、`node scripts/fx-extent.mjs`。
