# 开局三职业：套装、本命被动与外观

> 三套起手职业（疾风 `bolt` / 烈焰 `flame` / 壁垒 `ward`）决定开局四张法术、两条 0 级本命被动、壁垒的 10 点开局护盾与披风配色；格数与后续构筑三套一致。
> 数值源：`STARTING_KITS`（`src/logic/run.js`）、`CHARACTER_BUFFS` / `COMPASS_BUFFS`（`src/logic/progression.js`）、`KIT_STYLES`（`src/ui/kit-style.js`）。条文见[规则契约](<规则契约.md>)§6.4。

## 1. 三套开局

第一幕解封 6 格（`ACT1_STARTING_CELLS = [4, 5, 6, 7, 9, 10]`），三套只填 4 / 5 / 6 / 9。

| 职业 | 定位 | 本命被动（0 级） | 4 / 5 / 6 / 9 格 |
| --- | --- | --- | --- |
| 疾风 `bolt` | 疾行游走 · 高机动、快触发 | 轻盈步伐 移速 ×1.08 + 疾转轴心 触发间隔 ×0.92 | 寒霜飞弹 / 秘能弹 / 烈焰喷涌 / 圣光壁垒 |
| 烈焰 `flame` | 爆发连击 · 高伤害、长连击链 | 强能刻度 伤害 ×1.12 + 延续之链 连击窗口 ×1.25 | 烈焰喷涌 / 秘能汲取 / 荆棘藤蔓 / 秘能弹 |
| 壁垒 `ward` | 坚壁续航 · 高护盾、长无敌 | 庇护印记 护盾上限 40→50 + 坚韧余辉 无敌 +0.15s | 圣光壁垒 / 寒霜飞弹 / 秘能弹 / 秘能汲取 |

- 开局四张固定为**谐律形态**（`harmon`，伤害 ×0.82 = −18%，可参与联组），让第一波就能摆出联组，规则见[法术系统深挖](<法术系统深挖验收-2026-11-16.md>)。只带基础法术，星陨 / 审判之锤不进起手。
- 本命被动按 **0 级**各执行一次 `apply(stats, 0)`，没有等级。
- 数据全落在 `run` 上：`kitId`、`kitAffinity`、`characterStats`（`maxHp` / `speedMult` / `shieldCap` / `shield` 等）、`compassBuffs`；战斗层只读，未知 id 由 `getKit` 回退第一套。

## 2. 本命被动加权

`rollBuffWeighted(pool, rng, affinity = [], weight = 2)`：宝箱与罗盘抽到本命被动权重 ×2、其余 1，只消耗**一个**随机数；空池返回 `null`。这是路线倾向不是保底，一局仍可能抽不到。残响祭坛不读 `kitAffinity`，两套不叠加。被动池 11 条 × 5 级，数值见[内容规格表](<内容规格表.md>)。

## 3. 配件、选套与调试入口

同一张 `player_sheet.png` 加三处像素配件（披风 2×4、胸章 3×3、法杖尖端，`Player.drawKitAccents` 绘制），不新增美术、不改判定：疾风 teal `0x2f6f6c` / 翼 `wing`、烈焰 `0x8a2f28` / 余烬 `ember`、壁垒 `0x7a621f` / 盾 `ward`。

- 卡面（`LoadoutScene`）显示名称、`role`、一句 `tagline`、四张起手法术与两条本命被动名。
- 调试入口 `?kit=bolt|flame|ward`：`BattleScene` 从 `URLSearchParams` 读 `seed` / `kit` 交给 `createRun`，选套页同样读它预选，未知值回退疾风。

## 5. 已知边界

1. 加权不保证抽到，截图只有起手 5 秒，手感要打完整局。
2. 除壁垒 10 点盾外三套无开局属性差异，生命 / 拾取 / 无敌帧全来自本命被动本身。
3. 披风盖住背面膜一小块，远处靠颜色辨职业，属有意取舍；卡面不预演伤害。
