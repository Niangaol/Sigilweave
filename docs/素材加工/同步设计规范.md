# 画风同步设计规范 v1.0（2026-10-24）

> 背景：角色已从程序化像素绘制换成 AI 加工的 12 个素材（Loop Hero 风：硬色块 + 暗描边 + 2~3 层明暗）。
> UI/特效/背景的视觉语言要同步跟上，避免"精致角色 + 柔光 UI"的割裂。

## 一、从素材提取的视觉语言（决策依据）

对 `public/assets` 12 个素材做像素统计，主色分布：

| 角色 | 主要用色 |
| --- | --- |
| 近黑暗紫（描边/阴影） | `#240c24 #3c243c #0c0c24` |
| 低饱和中间调 | `#6c6c54`（khaki）`#849c6c`（sage）`#543c3c`（mauve） |
| 暖褐与骨白高光 | `#846c54 #cc9c6c #e4e4cc` |

**三条硬结论：**
1. **描边是素材的骨架**：每个精灵都有 1px 暗紫黑描边（不是纯黑），这是"硬朗像素"最直接的来源。
2. **中间调决定质感**：素材大面积是低饱和中间调，不是纯色块。旧 UI 从 near-black 直接跳到 brass 高光，缺中间层 → 显"扁"。
3. **明度关系**：背景更暗（素材底色在 #0c~#3c 区间），中间调角色才能"跳"出来。

## 二、同步后的绘制语言（所有 UI/特效遵守）

### 1. 三层结构（替代旧的"柔光 alpha 叠加"）
```
外描边（1px，C.outline / C.ink） → 本体（def 色 / 主题色） → 亮芯（1px，C.white / C.arcaneLight / C.brassLight）
```
- 禁止连续 alpha 柔光堆（0.1~0.4 的多层叠加）。
- 允许的 alpha 只有两种用法：① 整体淡出（元素生命周期）② 大面积薄雾/暗角（背景层）。
- 高光一律 1px 实心，不用渐变。

### 2. 面板结构（UI 容器）
```
外框：1px C.outline（最外）→ 1px C.brassDark 或 C.stoneLight（亮边）
内底：C.nightDeep / C.void（不透明，压住背后场景）
四角：3×3 铆钉（C.brass + 1px C.brassLight 高光点）
```
- 已有面板（HUD/罗盘/暂停/问答/幕间）统一这套框线，**不动任何布局坐标与命中区**。
- 标题条：C.brassDark 底 + C.brassLight 文字，与既有 E 编辑界面一致。

### 3. 特效结构（战斗层）
| 特效 | 结构 |
| --- | --- |
| 弹丸 | 外菱形描边(outline, r3) + 本体(def.color, r2) + 1px 亮芯；拖尾=离散像素点（3 档大小，不用连续 alpha） |
| 方位光迹 | 双线（outline 底 + color 主线）+ 流动亮块 2×2 实心 + 终点菱形带描边与亮芯 |
| 命中 | 菱形描边 + 本体 + 白核十字（4 向 1px） |
| 爆散 | 粒子 = 3×3（outline 底 + color 芯） |
| 联组链带 | brassDark 3px 底 + brass 1px 亮线 + 流动亮块；暗角保留 |
| 受击红边 | blood 4px 外 + bloodDark 2px 内（双线硬边） |
| 预警 | 瞄准线双线（outline+blood）；落点环双环硬边；地面加 attack_warning.png 素材条 |

### 4. 色彩纪律（不许破坏）
- 己方伤害/法术：暖金 `arcane/brass/parchment`；增益/资源：`teal`。
- 敌方：`blood/rot/bone/mute` 冷色或腐色。
- 青绿只表示"运行层/增益"，不得用于伤害。

## 三、分工与边界

| 谁 | 文件 | 内容 |
| --- | --- | --- |
| lead | Palette.js / Projectile.js / EffectsLayer.js / Enemy.js / Boss.js | 色板 + 战斗特效 + 预警 |
| ui-smith | src/ui/{Hud,SigilBoard,EncounterPanel,PauseMenu,board-decor}.js | 面板框线统一 |
| map-smith | src/ui/Background.js | 三幕背景压暗 + 暗角 + 中间调噪点 |

**铁律**：不改布局坐标、不改命中区、不改逻辑、不碰 Palette.js（只消费新增的 C.outline/khaki/mauve/sage/tan）。

## 四、验收

- 每个改动者必须实机截图自审：`node scripts/sync-shot.mjs <输出目录>`（dev server 需先起：`npx vite --port 5180`，BASE_URL 默认 http://localhost:5180）。
- 判定标准：新元素在 960×540 实机截图中"看得出是同一套美术"；角色仍是画面焦点；文字仍清晰。
- 最终由 lead 复核 `docs/素材加工/同步/after/` 五场景对比图。
