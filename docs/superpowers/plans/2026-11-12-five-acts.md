# 《共振法阵》五幕七场重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把现有的七幕线性结构改成「幕 1–5 / 场 1–7」两级结构：旧七套主题按原编号降级为七场，前 3 幕各 1 场、第 4 幕 = 沉钟书库→衡律法庭、第 5 幕 = 熔星锻炉→破晓之座；每幕 = 4 个小 Boss + 全部大 Boss（第 4/5 幕各 2 位）+ 本幕各场的 NPC；世界更大、刷怪更密、单幕约 5 分钟。

**Architecture:** 新增 `src/logic/acts.js` 作为唯一「幕↔场」映射源（CHAPTERS / chapterOf / stagesOf / encounterIdsOfStage / chapterMajorsCleared）。账目、等级、遭遇、地图点位、场次卡、HUD 一律以「场 stage」为主键（美术、地板、Boss 立绘、弹幕模板 1:1 复用旧七幕，零返工）；幕间工作台、通幕判定、结算里程碑以「幕 chapter」为主键。幕内换场由 `BattleScene.swapStage()` 原地重建世界完成，不切场景、不弹工作台，血量与构筑延续。

**Tech Stack:** Phaser 3.90 + Vite 5 + vitest 2（ESM、纯逻辑模块可在 Node 直接单测）。无新增依赖。

**Spec:** `docs/superpowers/specs/2026-11-12-five-acts-design.md`

## Global Constraints

- 全中文文案、文案内禁止 emoji（`tests/encounters.test.js` 与 UI 文案断言会红）。
- **七枚契约数量不变**：7 位大 Boss（boss-1…boss-7）仍各记一次账，开场「七枚契约钉入大地」与结局「七契尽解」文案不改。
- 幕→场固定映射，不得改动：第1幕=[1]，第2幕=[2]，第3幕=[3]，第4幕=[4,5]，第5幕=[6,7]。场序号 == 旧幕序号（美术/地板/立绘/主题名一一对应）。
- 每幕 4 个小 Boss：场 1/2/3 各带 a,b,c,d 四只；场 4/5/6/7 各带 a,b 两只（第4幕 = 4a,4b,5a,5b；第5幕 = 6a,6b,7a,7b）。
- 遭遇总数 34 条：NPC 7 + 小 Boss 20 + 大 Boss 7。
- 世界尺寸（按场，键 1..7）：2400×1800 / 2600×1900 / 2800×2000 / 2800×2100 / 2800×2100 / 3000×2200 / 3000×2200。
- 大 Boss 触发等级（按场）：5 / 10 / 15 / 20 / 24 / 28 / 32。
- ACTS（按幕）baseIntervalMs 1400/1200/1000/960/920、starts 2/3/3/4/4、unlocked 6/12/16/16/16。
- 不新增 npm 依赖；**不改** `package.json` / `vite.config.js` / `index.html` 的对外契约。
- 测试必须在独立进程里跑（`npm test` / `npm run build`）；run_code 沙箱内跑 npm 会报 spawn EPERM。冒烟与截图用 `tools.pwsh`。

## Review Focus

1. 第 4/5 幕里玩家在第二场（场5/场7）阵亡：结算必须记在**当前幕**，且不能把「已清空第一场大 Boss」当成通关（读 `summary.chapter` 而非 `summary.stage`）。
2. 第一场大 Boss 已解、换场后重进同一局（暂停菜单 restart / 刷新）：`run.majorBossStages` 必须让该场大 Boss 不再二次触发，`swapStage` 不能重复执行。
3. 换场瞬间：飞行中的弹丸/碎片/经验粒子、已开宝箱、事件点图标与标签必须全部清理，否则会留在错位坐标或重复结算经验。
4. 场 1–3 的 5 个事件点在最小合法世界（1600×1600）下仍满足：距边 ≥80、两两 ≥400、距出生中心 >240。
5. 换场后引擎时间与战斗状态：`engine.now` 不清零（HUD 计时与结算 elapsedMs 连续），玩家血量/护盾/无敌帧保留，罗盘（grid/board/combos）不重建。
