# 过场动画重做 · 契约碑铭剧场 设计规格

> 状态：待用户评审（2026-11-11）
> 触发：用户反馈「重做过场动画 添加更多细节，现在的太简陋了 缺乏辨识度」
> 适用代码：src/scenes/CutsceneScene.js、src/ui/cinematic-art.js、src/ui/cutscene-choreo.js、src/ui/story-art.js、src/scenes/StoryScene.js
> 本规格是 docs/superpowers/plans/2026-11-11-cutscene-diorama.md 的引用依据。

## 1. 问题诊断（基于 docs/cutscene/*.png、docs/story/*.png 实拍）

| 症状 | 证据 | 根因 |
| --- | --- | --- |
| 每类过场长得一样 | act/clear/death/victory 四张截图：同一暗紫底、同一铜框大卡片、同一符环 | 卡片固定居中（半宽 170、高 196），占 480×270 画布 65% 面积；所有类共用同一构图 |
| 场景几乎看不见 | act1 卡：背景只剩极淡尖拱/墓碑/烛台 | 卡片遮住中景；幕色只用于整屏染色，物件本身低对比 |
| 没有事件 | sigil/retry/return 三张截图完全同构，只有文字不同 | drawKindEvent 只处理 death/victory/clear，且只是叠色 |
| 空得离谱 | journey 第贰幕：画面 80% 是空暗场；开场 skyfall 几乎全黑 | 舞台只有 3–5 个远景剪影，没有前中后景，没有地面材质 |
| 物件没有材质 | 所有剪影都是单色块，无砖缝/木纹/锈/苔/水痕 | 没有「材质依附」概念，纹理只以随机点出现（被用户明确否决） |

**一句话根因**：过场把「标题卡」当主体、把「布景」当底纹；正确关系应反过来——布景是主体，文字是刻在布景上的铭文。

## 2. 目标与非目标

**目标**
1. 七幕各有可一眼辨认的轮廓、光源、主体物件（辨识度）。
2. 八类短过场各有一套「准备→行动→结果」的专属事件，结果残留在画面上（细节与叙事）。
3. 每帧绘制预算不升（≤700 指令），通过「静态布景预绘制」换取细节量。
4. 换场状态机、时间轴时长、跳过语义、文案、验收开关一律不变。

**非目标（明确不做）**
- 不改任何文案（ACT_CARDS / COMPACT / formatReport 的字符串与字数）。
- 不改 TIMELINES 毫秒数与 SKIP_GRACE_MS（tests/cinematics.test.js 的 900–1600ms 约束继续生效）。
- 不引入图片/贴图/精灵资源（保持纯程序化像素美术、零素材依赖）。
- 不改战斗背景 src/ui/Background.js（它绑定世界坐标与 RenderTexture，另属一套）。
- 不做渐变、模糊、阴影模糊、Math.random；所有随机用种子。
- 不做「只换背景色 / 只推镜头」的伪细节。

## 3. 设计原则

- **P1 一剧一景**：每类过场有自己的舞台装置与事件，禁止「同一构图换标题」。
- **P2 三拍**：准备（蓄力/点亮/推门）→ 行动（砸落/拔出/崩解/合拢）→ 结果（残留物留在画面：断钉、灰堆、血纹、七星连线）。
- **P3 材质依附**：纹理只能长在实体上（砖缝跟石碑、锈斑跟铜钉、苔跟水线、煤烟跟炉口、尘只出现在光柱里）。禁止全屏随机撒点、禁止齿状条纹冒充纹理。
- **P4 三层纵深**：远景（天/墙/光）→ 中景（主体结构，占画面宽 ≥1/4）→ 近景（压住画面下缘的遮挡物）。任何一幕缺任一层即视为未完成。
- **P5 卡片让位**：标题改为底部「碑座」铭文带；主体场景占画面上 62%。数字与标题压印在碑座上，不再浮在画面中央。
- **P6 幕色只上光源**：accent 只用于该幕的光源物件（月光/彩窗/星光/烛光/天平反光/炉火/晨光）与铭文细节，不做整屏染色。
- **P7 硬边像素**：整数坐标、1px 线、无抗锯齿依赖的图形；同参数同种子必须完全确定。

## 5. 分层架构（性能换细节）

| 图层 | depth | 内容 | 重绘频率 | 预算 |
| --- | --- | --- | --- | --- |
| veilG | 0 | 遮罩底（保持现状：盖住旧场景） | 每帧 | 现状 |
| **backG** | 1 | 远景静态 | **create 时一次** | ≤1300 |
| **midG** | 1.5 | 中景静态（主体+材质） | **一次** | ≤1300 |
| **foreG** | 1.8 | 近景静态（压边+地面） | **一次** | ≤900 |
| stageG | 2 | 活动件（火苗/雾/雨/灰/页/火星/涟漪） | 每帧 | 每帧总预算内 |
| sealG | 2.5 | 符环（降级为事件道具，见 §7） | 每帧 | 同上 |
| dustG | 3 | 浮尘 | 每帧 | 同上 |
| fxG | 3 ADD | 闪洪/火花 | 每帧 | 同上 |
| card | 4 | 碑座铭文 | 静态（文字对象已存在） | — |

- 每帧四层（stageG+sealG+dustG+fxG）合计 **≤700 指令**（不变）。静态层每帧成本只有 3 次 `setAlpha` 与 3 次整数 `setPosition`。
- 静态层透明度 = easeInOutCubic(cover)，与现有 veil 同步：cover 淡入、reveal 淡出，揭开时露出目标场景。
- 视差只用整数位移：back 0px、mid −1px、fore −3px（在 hold 期间线性推进），禁止缩放。
- 静态层一次绘制的合计预算 **≤3200 指令/幕**。

每幕必须给出：远景带、中景带、近景带、材质线（≥3 类，依附定义）、幕色用途（≤3 处光源）、三枚辨识标记（用于截图指纹核对）。尺寸为横屏 480×270 下的实际像素。

## 7. 八类短过场的事件规格

通用：事件只画活动件（stageG/sealG/dustG/fxG），布景来自当前幕；文案与时长不变；音效只复用现有 `sfx.cineIn/cineSwap/cineSlam/cineShatter/cineReveal/tick`。时间用 hold 内归一化 `holdP`（0→1），揭开始终保持结果。

**符环降级**：只有 boot / sigil / victory 用大符环（r 210 起）作主体；act / clear / death / retry / return 的符环半径 ≤90，且只在锚点处作事件道具（钉帽外扩、断口余波、刻线环）。

| 类 | 准备 | 行动 | 结果（残留） | 音效 |

| sigil | 0–0.28 契约钉自上方落下（拖影 2 段） | 0.28–0.45 触石：震屏 2px、石屑 8 粒、闪洪 1 次 | 0.45–1 符环从钉帽外扩 r 18→72 后静止（残留：钉立于石、3 条裂痕从钉脚辐射、石屑落地 6 粒） | cineSlam |
| act | 0–0.25 幕门缝光（门在锚点上方，光缝宽 1→6px） | 0.25–0.50 契约主剪影现身（12×40，逐幕配件），0.50–0.68 巨号幕数字压印到碑座 | 0.68–1 门留 4px 缝、剪影停住、碑座描边亮（残留：门缝光柱、剪影、数字） | cineSlam |

| retry | 0–0.20 断裂刻线（6 段断口） | 0.20–0.70 刻笔沿路径逐段描过（每 0.08 点亮 1 段） | 0.70–1 刻线合拢发光 + 笔尖余点（残留：完整刻线） | tick |
| return | 0–0.35 雾自两侧卷入（左 3 缕 + 右 3 缕） | 0.35–0.80 烛火逐个熄灭（3→2→1） | 0.80–1 只余中央一盏 + 雾沉到地面（残留：1 盏灯、雾带、2 处烟） | cineReveal |

**结果停留的硬要求**：任一 kind 在 holdP=1 时，残留物件必须仍在绘制（`residueAt(1)` 非空且与 `residueAt(0.9)` 相同）；揭开阶段残留随静态层一起淡出，不做「消失动画」。

## 8. 碑座（标题卡替代）规格

### 8.1 非紧凑卡（act / clear / death / victory）
- 面板：横屏 `y0 = H-84`，高 84，通栏 480；竖屏 `y0 = H-104`，高 104。填充 C.void alpha 0.88；上沿 1px 铜线 alpha 0.55；四角 3×3 铜铆钉；底边 1px 暗线；2 条 1px 凿痕（固定种子）与 4 点苔（贴底边）。
- eyebrow：x=14, y=y0+6，字号 7，accent。
- 标题：x=14, y=y0+16，字号 20（竖屏 22），左对齐；act 逐字砸落（每字 x = 14 + i*(字号+6)）。
- 分隔线：y=y0+42，x=14→300，1px 铜暗；中央 3px 菱形。
- 副标题：x=14, y=y0+44，字号 8，宽 300，最多 2 行。
- stats（clear/victory）：4 列，x=306/346/386/426，label 字号 6（y0+14），value 字号 11（y0+24），列间 1px 竖线。
- hint：右对齐 x=466, y=y0+70，字号 6，HEX.mute。
- 幕数字水印：act 时 x=450, y=y0-56，字号 46，alpha 0.18，accent；其余类 x=450, y=y0+20，字号 28，alpha 0.12（I–VII 用 drawNumeral 的线稿版）。
- 面板上方 1px 阴影线（C.nightDeep alpha 0.6，y0-1），把铭文带与场景分开。

### 8.2 紧凑卡（boot / sigil / retry / return）
- 小碑 176×44，中心 `(cx, round(H*0.66))`（横屏 y=178，面板左下角 y=156）；填充 C.void alpha 0.82；铜框 1px + 四角 3×3；标题字号 13、水平居中、`y = panel.y + round((panel.h - 13)/2) = 172`（`Palette.addText` 默认 origin (0,0)，需 `setOrigin(0.5,0)` 才能以 cx 为 x 居中）；无 eyebrow/subtitle/stats。
- 竖屏时 y = round(H*0.74)，避免压住底部触控台。

### 8.3 文字对象与动画接口（保持现有 choreo 字段）
`card.titleChars`（act 逐字）、`card.titleText`（其余）、`card.statValues`、`card.statBaseY`、`card.titleBaseY` 五个字段继续存在（`src/ui/cutscene-choreo.js:131-154` 依赖它们），因此编舞代码不需要改接口。

容器仍建在 `add.container(cx, cy)`（不改容器坐标，否则 `card.setY(card.y + 2)` 的抖动语义会漂），`plinthLayout` 返回的是画布绝对坐标，进容器前统一过 `toLocal(p, cx, cy)` 转成局部坐标。

## 9. journey 六幕（5200ms 单镜头）

每幕沿用 §6 对应幕的布景（可简化 20%），但加「三拍」长镜头事件：
- swamp：钟摆摆动（1 个来回）→ 钟声波纹 3 圈扩散到水面 → 沼水倒影抖动后稳住。
- star：星纹环旋转 4° → 一颗陨星划过 → 地面陨坑亮一次后暗下。
- library：书页翻飞（3 页）→ 铜钟自鸣 1 次 → 书页落回阅读台。
- court：天平倾斜到一侧 → 判词卷从盘中滚落到栏杆 → 栏杆落定。
- forge：炉火涨 3 层 → 铁锤砸落 1 次（震屏 1px）→ 火星落地熄灭。
- sunrise：晨光带横扫（整数位移 4px）→ 北斗连线逐星点亮 → 光池铺满地面。
- 文字仍用现有 jLabel/jSubtitle 位置，只把字幕加 1px 铜线分隔。

## 11. 验收（可量化）

1. **细节量（空白率）**：每张 hold 截图降采样 32×18，按「与画面主色差 > 12 的像素占比」计 ink ratio；要求 act/death/clear/victory ≥ 0.55，journey ≥ 0.50（当前 journey 约 0.20）。
2. **辨识度（指纹）**：七幕 act 截图两两指纹距离 ≥ 0.18；同一幕不同 kind 的指纹距离 ≥ 0.10。指纹 = 32×18 的 12 级亮度格子。
3. **预算**：静态层单带 ≤1300、单幕 ≤3200（一次性）；每帧四层 ≤700（回归 tests/cutscene-choreo.test.js）。
4. **确定性**：同参数两次绘制指令数相等；坐标全有限整数（沿用现有 stub 抛错）。
5. **不回归**：npm test 全绿；npm run build 通过；cutscene-shot.mjs（15 项 + 新增指纹/画廊）、story-shot.mjs、ending-shot.mjs 全绿。
6. **手感**：时间轴 900–1600ms 不变；跳过在 150ms 后仍生效；竖屏 480×760 不越界。

## 12. 风险与回退

| 风险 | 处置 |
| --- | --- |
| 静态层一次绘制造成 create 卡顿 | 绘制发生在 cover 阶段（旧场景已暂停）；若 >8ms 再拆成两帧预热 |
| 碑座压缩文字可读性 | 标题字号 20/22、字幕 8px 双层描边；竖屏加高到 104 |
| 七幕布景工作量 | 每幕独立文件 + 独测试，可并行；样板第一幕后复制结构 |
| 指纹阈值过严导致抖动 | 阈值写进脚本常量，允许按实测基线调整一次并记录 |
| 与 journey/开场/结局互相影响 | Phase B/C/D 顺序落地，每阶段跑全量脚本 |

## 13. 术语

- **碑座**：画面底部的铭文带，替代原居中标题卡。
- **静态层**：create 时绘制一次、每帧只改透明度与位移的 Graphics。
- **活动件**：每帧重绘的少量动态元素。
- **锚点**：人为钉死的整数坐标，事件与布景共享的对接点。
- **残留**：事件结束后仍留在画面上的结果痕迹。
- **指纹**：降采样后的亮度格子，用于量化辨识度。
