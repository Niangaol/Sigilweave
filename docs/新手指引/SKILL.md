# 共振法阵 · 灵宠新手引导 Skill

## 1. 用途与边界

本 Skill 产出《共振法阵 Sigilweave》的**游戏内新手引导设计 + 逐字文案 + 可导入的内容数据**，用于提交领导评审；评审通过后，由开发按第 9 节的接入点把内容挂进游戏。

- 服务对象：首次进入游戏的玩家。
- 载体：一只常驻的灵宠「墨宝」头像/立绘 + 对话气泡，配合画面高亮。
- 覆盖范围：开场与第一幕（G00–G04）、第二幕准备与战斗（G05–G08）、第三幕完整引导（G09–G11）、第四幕及以后一句话提示（G12）。
- 硬边界：**不修改游戏源码、不改数值、不暴露 Boss 问答答案**；只产出设计文档、文案与数据文件。

## 3. 灵宠人设：墨宝（符火灵猫）

形象素材：`assets/灵宠-墨宝-像素.png`（32×34 RGBA 像素精灵，用 `Palette.js` 真实色板程序化绘制，生成脚本 `scripts/generate_pet_sprite.py`）。设 计特征：通体墨蓝黑、额间青焰符印、青蓝大眼、卷尾、四周漂浮叶片。
`assets/灵宠-墨爪.jpg` 是用户最初提供的插画参考（仅作形象设定参照，**不得直接用于游戏**）。

> **画风铁律**：本游戏是西幻像素风（480×270 逻辑画布、硬边色块、无渐变无模糊）。引导 UI 与头像必须像素化：头像用 `image-rendering: pixelated` 放大、气泡用硬边黄铜描边面板、字体走 `Palette.js` 的 FONT（黑体）与 FONT_DISPLAY（衬线大标题）。禁止圆角卡片、阴影、渐变、矢量平滑图标。完整规范见 `references/visual-style.md`。

- 定位：被法阵唤醒的小灵猫，自称「宝」，是玩家（刻阵者）的贴身指引。
- 性格：好奇、话多、护主、胆子小却爱逞强；紧张时会炸毛，玩家变强时会得意。
- 称呼玩家：主推「刻阵者」（贴合世界观），卖萌时可叫「主人」；Boss 战用「刻阵者」正称。
- 状态提示：说话时额间符印随情绪明灭（开心=亮青，认真=稳定，紧张=闪烁）。

### 3.1 语言风格（参考王者荣耀「灵宝」的陪玩感，但用词全部本地化到本游戏）

| 维度 | 规则 | 正例 | 反例 |
| --- | --- | --- | --- |
| 句长 | 一句一屏，短句，手机可读 | 「主人！右下角那个是罗盘哦～」 | 长段落说明四大机制 |
| 语气词 | 高频使用 喵/呀/啦/哦/呢/嘛/哒/喏 | 「踩亮就出手啦！」 | 「踩亮即可触发攻击。」 |
| 自称/称呼 | 宝 / 刻阵者 / 主人 | 「宝给你讲明白～」 | 「本系统提示如下」 |
| 情绪 | 用括号标注情绪与动作 | （耳朵一抖）「等一下！」 | 干巴巴一句话 |
| 结构 | 抓注意 → 讲机制 → 收尾鼓励 | 「看罗盘！金线跳到哪格，哪格就打～记住哦！」 | 只讲机制没有陪伴感 |
| 拟声 | 偶尔 呼——/嗖/嗡 | 「嗖——脉流跳走啦！」 | 滥用表情包 |

### 3.2 术语必须逐字正确

脉流、法阵、符印、符位、碎晶、罗盘、踩亮、吞跳、联组、断链、幕间构筑、构筑、誓约、铭文、出口、中继、熔炉、断流、静默、输出/辅助/空位。

### 3.3 三条禁止

1. 不剧透 Boss 问答答案；只教「线索都在对白与碑文里，答对直接处决」。玩家卡住时给提示而非答案。
2. 不打断操作：引导只在安全时机（场景切换/弹窗前/事件点靠近）出现，战斗中最多 1 句短提示。
3. 不重复：同一条 guide id 一局只出现一次，重开重置。

## 4. 触发模型

引导以 `guide id` 为单位，每个 id 有触发条件、出现次数、气泡时长、高亮区域。完整数据见 `assets/guide-content.json`。

| ID | 触发时机 | 场景 | 内容摘要 |
| --- | --- | --- | --- |
| G00 | 首次进入选套装界面 | LoadoutScene | 墨宝自我介绍、这一局结伴而行 |
| G01 | 第一幕战斗开场 | BattleScene(act1) | 走位 / 罗盘 / 踩亮 / 拾取 / 暂停观察 |
| G02 | 第一次升级选牌前 | BattleScene 升级弹窗 | 三选一进手牌，不自动上阵 |
| G03 | 首次靠近事件点 | BattleScene 事件点 130px 内 | 问答机制、答对处决 |
| G04 | 等级达到 5（大 Boss 前置） | BattleScene(act1) | 大 Boss 问答提示，不剧透答案 |
| G05 | 第一幕通关进入幕间 | IntermissionScene | 「第一幕结束，进入第二幕准备」过渡语 |
| G06 | 第二幕准备界面出现 | IntermissionScene(act2) | **逐区域讲解构筑台**（对应截图） |
| G07 | 出发进入第二幕战斗 | BattleScene(act2) | 12 格 / 3 脉流 / 新机制 / 通关要求 |
| G08 | 等级达到 10 | BattleScene(act2) | 第二幕大 Boss 问答提示 |
| G09 | 第三幕战斗开场（journey 后） | BattleScene(act3) | 16 格全开 / 1 秒间隔 / 新怪 / 星陨 / 通关要求 |
| G10 | 第三幕首次遇到咒誓主教（可选） | BattleScene(act3) | 瞬移三连弹的应对 |
| G11 | 等级达到 15 | BattleScene(act3) | 第三幕大 Boss 问答提示 |
| G12 | 第四幕及以后每幕开场 | BattleScene(act4+) | 一句话提醒，不展开 |

同一时刻多个条件满足时，按 id 顺序播放；G06 优先级最高，可打断其他提示。G10 为可选提醒（战斗中最多 1 句短提示，不打断操作）。

## 5. 对话卡片数据格式（给开发接入用）

每条引导是一张卡片，字段固定，便于直接驱动 UI：

```json
{
  "id": "G01",
  "trigger": { "scene": "BattleScene", "act": 1, "event": "sceneEnter", "oncePerRun": true },
  "pet": { "name": "墨宝", "emotion": "excited" },
  "lines": ["主人！第一幕来啦～", "用 WASD 或方向键走位，怪潮从四周压过来哦！"],
  "highlight": "touchControls",
  "advance": { "type": "tap" },
  "voiceCue": "meow"
}
```

`highlight` 可取：`compass`（右下角法阵罗盘）、`grid`（法阵盘）、`reward`（顶部奖励区）、`hand`（手牌区）、`runes`（铭文区）、`oaths`（誓约区）、`depart`（出发按钮）、`touchControls`（走位区）、`eventPoint`（事件点）。

## 6. 第一幕引导脚本（G00–G04）

以下为**逐字文案**，括号为演出提示，不朗读。完整版见 `references/chapter-scripts.md`。

- **G00**（选套装界面）：（从屏幕下角探出头）「喵～主人！我是墨宝，被这座法阵吵醒的小灵猫。这一局宝陪你走，别怕哦！」「先挑一套初始法术吧——疾风、烈焰还是壁垒？选完我们就进墓园啦～」
- **G01**（第一幕开场）：（耳朵一抖）「看这里！右下角的 4×4 是罗盘，代表你周围的方位哦。」「金线叫脉流，它跳到哪一格，哪一格的符印就自动出手——你只管走位躲怪！」「踩亮就打啦；格子还在冷却会被吞跳，记住哦～」「怪掉了碎晶和经验粒子，走过去捡起来，升级能三选一拿新卡！」「按住空格能暂停观察法阵，看不清就按一下～」
- **G02**（首次升级）：「叮！升级啦～三张牌里选一张——符印卡会成为你这一场的技能，按 1/2/3 就能放；辅助卡是被动增益，不占技能格哦！」
- **G03**（靠近事件点）：「前面有发光的地方！走过去会触发问答——线索就藏在刚才的对白和碑文里。答对可以直接消灭 Boss，答错才要打架哦～」
- **G04**（等级 5 大 Boss 前置）：（符印开始闪烁）「刻阵者，岭上那位觉醒了……先读它的话，答案就在里面。宝不剧透，但你一定找得到！」

**第一幕通关要求（必须让玩家知道）**：等级达到 **5** → 触发大 Boss「烬冠骑士·白焰祭坛的僭主」问答 → 答对直接处决、答错进入实战 → 解决后通幕。第一幕基础投射间隔 1.4 秒、2 条脉流、解封 6 格。

## 7. 第二幕引导脚本（G05–G08，含截图逐区讲解）

**G05**（进幕间）：「第一幕清干净啦！下面进入幕间构筑——宝带你把法阵重新排一遍～」

**G06**（第二幕构筑界面，逐区讲解，是本次核心）。截图见 `assets/第二章构筑界面.jpg`，逐项对照见 `references/ui-mapping.md`：

1. 顶部标题：（抬头）「这是幕间构筑台哦。现在准备的是第 2 幕，奖励还有 3 轮，法阵已经解封 12 格啦～右边的碎片是你的钱，买铭文要用。」
2. 顶部奖励卡：「最上面三张是三选一奖励，点『领取』拿进手牌。三轮领完才能出发哦！」
3. 三步引导条：「跟着这条走：1 选牌 → 2 放位 → 3 绑定/收回，宝在旁边给你打灯～」
4. 法阵盘（4×4）：「左边这块就是法阵盘。1–16 号符位，写着『封印』的还没解封，写着『空符位·从手牌放入』的可以装卡。像『烈焰喷涌 5号 铭0 出4』，就是 5 号装了烈焰喷涌，铭文 0 个、出口 4 个方向～」
5. 统计区：「这里看输出/辅助/空位数量，还有选中格的间隔和冷却。底下那行『三轮奖励洗完后出发；法阵必须保留至少两张非中继输出』是出发门槛，一定要记牢哦！」
6. 输出/辅助：「符印负责打伤害，辅助负责改机器运行；主槽只能二选一，二者互斥～」
7. 誓约：「三个誓约全局只能立一个：孤星、守夜、殉道。选了再点一次就取消啦。」
8. 手牌区：「右边是手牌，点一张再点左侧符位就能装上。要放辅助的话，还得再点一个相邻的输出符印绑定目标哦～」
9. 出口编辑：「点『出口编辑』能开关这一格的上/下/左/右出脉方向，至少留一个出口，或者先装断流铭文。」
10. 铭文区：「四种铭文各 8 碎片：熔炉加伤、中继不出手但加速、断流保留出口、静默压邻格冷却。每格两个铭文槽，拆了返还 6 折哦～」
11. 出发：「都弄好就点『确认构筑 · 出发』！宝再念一遍：三轮领完、至少两张非中继输出、校验没报错，才能走！」

**G07**（进入第二幕战斗）：「第二幕到啦！法阵扩到 12 格、脉流变成 3 条，投射间隔 1.2 秒，怪更密还有精英哦。升到 10 级，女爵就会现身——宝陪你！」
**G08**（等级 10）：（符印急促闪烁）「刻阵者，女爵的契约挂在铜钟里……仔细听她说了什么，答案藏在那儿。」

**第二幕通关要求（必须让玩家知道）**：等级达到 **10** → 大 Boss「溺誓女爵·沉钟祭坛的债主」问答 → 答对直接消散、答错实战 → 解决后通幕。第二幕 12 格 / 3 脉流 / 1.2 秒间隔 / 有精英「缝合尸魁」。

**关键提醒**：通幕不看计时、不用清完事件点；只看大 Boss 是否被解决。这一点要在 G01 和 G07 都明说。

## 8. 第三幕引导脚本（G09–G11，星陨王庭·天玑）

第三幕是**单场幕**，通关口径：等级达到 **15** → 大 Boss「无昼织王·终星祭坛的囚徒」问答 → 答对直接处决、答错实战 → 解决后通幕。权威数值见 `references/game-rules.md` 第六节。

- **G09**（第三幕开场，journey 后）：（踩着星屑蹦出来，尾巴翘得老高）「刻阵者，第三幕·星陨王庭到啦～」「这一次法阵 16 格全开！投射缩到 1 秒，脉流还是 3 条哦。」「多了新怪：会瞬移放三连弹的『咒誓主教』，还有幽誓女妖、虚空符灵和黄铜守誓者～」「别硬拼——主教瞬移后会停半秒才开火，趁那会儿横着躲开！」「这一场通关能拿到『星陨』符印，半径 70 的范围伤害，记得装上哦～」「升到 15 级，无昼织王就会现身。通幕还是老规矩：解决大 Boss 就行！」
- **G10**（首次遇到咒誓主教，可选）：（耳朵贴平，爪子指向远处）「看！那只瞬移的咒誓主教——」「它总保持距离，隔几秒就闪到你侧边，停半秒后连发三颗弹。」「看到它停下来，就赶紧横着挪开哦！别站在原地挨打～」
- **G11**（等级 15）：（额间符印急促闪烁、尾巴炸毛）「刻阵者，织王在星图上留下了真名……」「终止誓词要填哪个名字？线索就在星图和它对白里。」「宝不剧透，你一定找得到！」
- **可选·局外成长**（首次击杀 boss-3，接入 meta 时用）：「刻阵者厉害！宝的感觉也跟着变强了喵～」

**第三幕通关要求（必须让玩家知道）**：16 格全开 / 3 脉流 / 1000ms 间隔 → 升到 **15** 级 → Boss「无昼织王」问答（答案「伊斯缇尔」**禁止剧透**，只提示线索在星图和对白）→ 答对直接处决（+16 碎晶 + 星陨符印）、答错实战（裂空七线 7 发扇形弹）→ 解决后通幕。

## 9. 领导确认清单（评审决策点）

提交评审时请领导明确以下 6 项，确认后再接入：

1. 灵宠名字「墨宝」与称呼（刻阵者 / 主人）是否采用；备选名：小焰、墨团、阿纹。
2. 引导音量：是否每条都弹（现有 G00–G11 共 12 组）还是只保留 G00/G01/G06/G07/G09 五条核心；G10 咒誓主教提醒默认可选。
3. 是否加配音/音效（当前仅预留 `voiceCue` 字段）。
4. 是否允许「跳过全部引导」按钮，以及再次观看入口（建议标题页 H 玩法说明旁加「灵宠引导」）。
5. Boss 问答策略：当前为「不剧透 + 卡住给提示」，是否改为「直接给答案」。
6. 第四幕及以后（G12）：是否只做一句话提示，还是像第三幕一样补完整脚本。
7. 第三幕新精英「咒誓主教」提醒（G10）是否默认开启——它是可选战斗中提示，部分团队不喜欢战斗中被打断。

## 10. 接入点（评审通过后给开发）

- `src/scenes/LoadoutScene.js`：G00。
- `src/scenes/BattleScene.js`：G01/G02/G03/G04/G07/G08/G09/G10/G11/G12；监听 sceneEnter、升级弹窗、事件点进入距离 ≤130、`run.level` 达 5/10/15 的瞬间，以及第三幕咒誓主教首次出现。第三幕 journey 过场（约 5840ms）播完、进入 BattleScene(act3) 后再触发 G09。
- `src/scenes/IntermissionScene.js`：G05/G06；在 `paint()` 后按 `draft.act===2` 触发。第三幕前的幕间构筑沿用 G06 讲解逻辑（此时副标题为 `第 3 幕准备 · 奖励 3 轮 · 已解封 16/16`，16 格全开无「封印」格）。
- 新增轻量 UI 组件：像素灵宠头像（assets/灵宠-墨宝-像素.png，`image-rendering:pixelated`）+ 硬边黄铜对话气泡 + 高亮描边；advance=tap/auto。UI 绘制复用 `src/ui/Palette.js` 的 `pxRect`/`pxFrame`/`addText`/`drawGlyph`，不要用 DOM 圆角卡片。
- 存档字段：`run.guideSeen = { G00: true, ... }`，一局内去重；新局重置。
- 内容数据直接读 `assets/guide-content.json`，文案与代码解耦，方便领导改字不碰逻辑。
