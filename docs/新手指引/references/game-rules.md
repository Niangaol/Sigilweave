# 游戏规则速查（仅用于新手引导文案的事实核对）

> 唯一权威：本地仓库 `../Sigilweave` 的源码。设计稿 v2.0、`docs/规则契约.md` 的部分数值为历史版本，禁止引用。
> 校验日期：2026-11-16 · 源码提交 `0a48bab`

## 一、游戏定位

- 类型：类幸存者 × 牌组构筑 × 空间编程（Phaser 3，H5 单页）。
- 一句话：你用双手在怪潮中求生，用一座刻满符文的法阵决定你活下来的方式。你不点击攻击，你只设计法阵——它替你打出每一发法术。
- 核心循环：走位躲怪 → 脉流在 4×4 格间跳跃、踩格触发符印自动攻击 → 拾取碎晶/经验 → 升级三选一 → 事件点问答 → 大 Boss 问答/实战 → 通幕 → 幕间构筑 → 下一幕。
- 全局胜负：解决第七场大 Boss `boss-7 破晓之王·厄俄斯` = 通关（标题「契约终结」）；生命归零 = 失败（标题「魂火熄灭」）。

## 二、场景流程

BootScene → StoryScene（开场字幕 6 镜）→ TitleScene → LoadoutScene（选套装）→ BattleScene（场1–7）→ 幕间 IntermissionScene（4 次）→ GameOverScene / StoryScene 结局。
幕内换场（场4→5、场6→7）不开幕间、原地 1.6s 场次卡。

## 四、第一幕要点

- 参考时长 210s；地图 2400×1800；密度 ×1.00；事件点 5 个（1 NPC + 4 小 Boss）。
- 解封 6 格 `[4,5,6,7,9,10]`（T 形），套装实际占 4 格（4/5/6/9）。
- 第一幕 NPC：艾琳·灰烬祭坛的守灯人（奖励 8 碎晶 + 治疗 15）。
- 小 Boss：守墓傀儡东/西、拾骨守夜人南/北（各 6 碎晶）。
- 大 Boss：烬冠骑士·白焰祭坛的僭主（12 碎晶 + 随机罗盘增益 + 固定卡「寒霜箭」）。

## 六、第三幕要点（星陨王庭 · 天玑）

- 参考时长 230s；地图 2800×2000；密度 ×1.20（刷怪间隔 ×0.88）；**16 格首次全开**；3 条脉流；间隔 **1000ms**。
- 单场幕（叙事幕 chapter=3、玩法场 stage=3）；HUD 显示「第三幕 · 天玑」。
- 入场过场 journey：「第叁幕 · 星陨王庭」/「星纹垂落如审判。最后一位契约主，记得所有名字。」（约 5.84s）。
- 本场固定法术奖励：**星陨**（半径 70 区域 22 伤害／内圈 -30%）。Boss 解决后发到手牌。
- 新精英：**咒誓主教**（生命×3.5、接触伤害 3、瞬移施法者）——保持约 110px，每 4.2s 瞬移侧翼，停 0.5s 后以 0.15s 间隔发三连弹。引导要点：「瞬移后停半秒才开火，趁机横着躲」。
- 新杂兵：幽誓女妖（快、脆）、虚空符灵（血厚）、黄铜守誓者（血厚×4.2、慢、接触伤害 4）。
- 事件点 5 个：NPC 莉芙拉·星陨圣所的织誓者（8 碎晶 + 治疗 15）+ 4 小 Boss（裂瞳主教·东席/西席、星窗执事·左廊/右廊，各 6 碎晶）。
- 大 Boss：**无昼织王·终星祭坛的囚徒**（血量 200、护甲 0、接触伤害 12、立绘 boss_void）；弹幕「裂空七线」7 发扇形（伤害 8、预警 600ms、间隔 1600ms）。答对直接处决（基础 12 + 问答 4 = 16 碎晶 + 星陨 + 罗盘增益），答错（「空名无法终止契约，织王展开夜幕」）进入实战。

- 通幕卡：`第 3 幕 · 完成` / `契约解除` / `星陨王庭的契约主已归于沉默，法阵把这一场的刻痕收进核心。` / hint `进入幕间工作台 · 重排罗盘`。

## 七、核心术语（逐字）

| 术语 | 定义 |
| --- | --- |
| 格 / cell | 4×4 法阵中的一格，id 0..15 |
| 脉流 / signal | 在格之间跳跃的信号，一次只有一个驻留点 |
| 跳 / hop | 脉流从一个格移动到相邻格的一次移动 |
| 触发 / trigger | 脉流踏上某格且该格冷却就绪，执行该格符印 |
| 吞跳 / blocked | 踏上了但该格仍在冷却，本次不触发 |
| 联组 / combo | 同一脉流连续踩中指定序列后的追加结算：对偶 +20%、直线三连末格 +40%、折线三连各格 +45%、环封四格各格 +80% |
| 断链 | 吞跳、保底改道、脉流消散都会打断进行中的联组 |
| 符印 | 占主槽、踏上即触发的输出卡，共 16 张 |
| 辅助 | 占主槽、不释放符印，改变机器运行参数，共 6 张；主槽二者互斥 |
| 共鸣石 | 正交邻格间隔与冷却 -25%（乘算 0.75^n） |
| 铭文 | 每格 2 槽，4 种：中继 / 熔炉 / 断流 / 静默；每个 8 碎晶，拆卸返 60%（4 碎晶） |
| 誓约 | 全局槽，最多 1 个：孤星 / 守夜 / 殉道 |
| 出口 | 每格出口方向集合，默认正交四邻；幕间可编辑，至少保留一个或装断流铭文 |
| 碎晶/碎片 | 掉落货币，需拾取；普通杂兵 45% 掉 1 颗，精英必掉 4 颗 |
| 手牌 | 卡牌库存，升级/奖励获得的卡先入手牌，不自动上阵 |
| 构筑 / draft | 主槽/铭文槽/出口/誓约的配置快照，幕间编辑、出发提交 |
| 刻阵者 | 玩家的世界观称谓 |

## 八、操作（逐字 UI 文案）

- WASD / 方向键：移动，镜头随行。
- 按住空格：暂停观察，松开继续（提示「观察中 · 松开空格继续　（Esc 打开菜单）」）。
- Esc → E：暂停菜单进入法阵编辑；升级时点击卡牌或按 1/2/3。
- 暂停菜单：`Esc 继续战斗` / `R 重开本局` / `T 返回标题` / `E 编辑法阵` / `M 音效 开|关`。
- 触屏：虚拟方向键 + 暂停按钮；提示「方向键 走位　·　　按钮 打开菜单」。
- 所有选择/确认界面都可用鼠标点击完成；用手牌是「点选手牌→点格子」，无拖放。

## 九、幕间构筑台逐字文案（`src/scenes/IntermissionScene.js`）

- 标题 `幕间构筑`；副标题 `第 N 幕准备 · 奖励 N 轮 · 已解封 N/16`；右上 `碎片`。进入第三幕时为 `第 3 幕准备 · 奖励 3 轮 · 已解封 16/16`。
- 奖励卡按钮：`<卡名>  领取`；卡下方 hint 取 `CARD_HINTS`。
- 三步引导：`选牌` / `放位` / `绑定/收回`（`src/ui/editor-ui.js:45-47`）。
- 初始提示：`三轮奖励选完后出发；法阵必须保留至少两张非中继输出。`
- 领取完提示：`三轮奖励已领取 · 选右侧手牌，再点左侧符位放置`
- 格子副文案：`N 号 · 从手牌放入` / `N 号 · 未解封` / `N号 铭M 出K`（M=铭文数，K=出口方向数）
- 统计行：`输出 N / 辅助 N / 空位 N`；`上幕 触发 N · 击杀 N`；`N 号 · <卡名>　间隔 X.XXs / 冷却 Y.YYs`；`铭文 … · 出口 …`
- 誓约：`孤星` `守夜` `殉道`；`未立誓（全局生效，最多一个）`；`已立誓：<名>`。
- 手牌：`手牌 N 种 / N 张`；`已选 <卡名> · 点左侧空符位放置`；`出口编辑`。
- 铭文按钮：`<铭文名> 8碎`；槽位：`铭文槽 1 空` / `铭文槽 2 空` / `拆 <铭文名>`。
- 出发按钮：`确认构筑 · 出发`；出发条件（`src/logic/workshop.js:139-149`）：三轮奖励领完 + 构筑校验通过 + 至少两张未装中继的输出符印。
