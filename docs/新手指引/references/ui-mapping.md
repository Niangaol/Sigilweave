## 引导讲解顺序建议

G06 按「标题(1) → 奖励(2) → 步骤条(3) → 法阵盘(4) → 统计(5,6,7) → 誓约(8) → 出发门槛(9) → 手牌(10,11) → 出口编辑(10) → 铭文(12,13) → 出发(14)」顺序逐条弹气泡，每条高亮对应区域。
一次只弹一条，点屏幕继续；可在领导确认后改为「合并为 4 条核心提示」。

## 事实核对注意

- 截图底部文字因拍摄模糊看似「洗完后出发」，源码原文为「选完后出发」，文案必须写「选」。
- 截图里 `碎片 31` 是该局余额，引导不要硬编码数字，用变量 `{shards}`。
- 铭文价格 8 碎晶是固定值（`workshop.js:115`），拆卸返还 `floor(8*0.6)=4`。
- 出发校验的「至少两张未装中继的输出符印」来自 `workshop.js:145-147`，不要写成「两张符印」。
