## 五、这三天反复验证出来的四条工程教训

1. **测试通过 ≠ 视觉到位**。翻车过的例子：悬停层挂错父节点被镜头甩飞、UI 被重建层盖住、按钮状态从未着色、手牌统计 TDZ 打断整页绘制。这些都只有"真浏览器截图/真实点击"能抓到，所以每轮验收都在补截图探针（`text-shot` / `scene-shot` / `probe-shot` / `mow-fx-shot`）。
2. **均值验收不能写成逐局保证**。受阻率三幕均值 24.00%/16.92%/19.47% 在 15–25% 区间内，但第一幕个别种子到 28.46%——文档如实列出，不把"均值达标"包装成"每局都达标"。这个诚实度值得保持。
3. **数值先仿真再落地**。78/101 密度那版是被纯逻辑仿真（`density-sim.mjs`）否掉的，不是被手感否掉的——比实机试十遍都快。
4. **文档会滞后于代码，而且会被当成事实引用**。`交付说明` 第 96 行和 `大地图验收记录` 第 237 行还写着"移动端/触摸未适配"，而手机兼容早在 `8c3db1c` 就上线了。这类旧句下次会被别的 AI（或你自己）当真，建议这轮顺手改掉。
