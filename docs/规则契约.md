# 共振法阵 · 规则契约（P0 冻结版）

> 布局修订：以游戏地图为主画面，法术罗盘固定右下角小窗，取消上下分屏及独立过渡带（用户 2026-10-23 明确要求）。

> 版本 0.1 ｜ 2026-10-23 ｜ 依据 共振法阵_游戏设计稿_v2.0.md 与 P0 仿真实测
> 本文件是实现的唯一规则依据。设计稿与本文件冲突时，以本文件为准；标「实测修正」的条目是被数据推翻的原稿假设。

## 0. 术语

| 术语 | 含义 |
| --- | --- |
| 格 / cell | 4x4 法阵中的一格，id 0..15，row=floor(id/4)，col=id%4 |
| 脉流 / signal | 在格之间跳跃的信号，一次只有一个驻留点 |
| 跳 / hop | 脉流从一个格移动到相邻格的一次移动 |
| 触发 / trigger | 脉流踏上某格且该格冷却已就绪，执行该格符印 |
| 吞跳 / blocked | 踏上了但该格仍在冷却，本次不触发 |
| 联组 / combo | 同一脉流连续踩中指定序列后的一次追加结算 |

## 1. 槽位模型

1. 每格有 1 个主槽 + 2 个铭文槽。
2. 主槽只能放「符印」或「辅助」之一，二者互斥。辅助必然占用一个输出位，这是它的机会成本。
3. 铭文不占主槽，插入即固定；拆除返还 60% 实际支付成本（向下取整）。
4. 誓约是全局槽，同时最多装备 1 个，幕间可替换，不占法阵格。
5. 联组不是卡，由空间结构自动成立，不消耗资源。
6. 依赖「本格伤害」的辅助（时之沙漏、献祭）改为作用于一个指定的正交邻格，不允许输出与辅助同格共存。
7. 战斗内禁止任何改阵、选牌、升级操作；这些只在幕间发生。

## 2. 时间与传播

### 2.1 时钟

- 纯逻辑模拟时钟，单位毫秒；事件队列按 (time, sequence) 稳定排序。
- 禁止用 setTimeout / setInterval 驱动玩法。
- 暂停、失焦、幕间一律冻结模拟时钟；回前台保持暂停，不补算后台时间。
- 跨幕清空事件队列、在途脉流、联组进度、临时增益；保留构筑与资源。
- 同一 seed + 同一指令序列必须产生完全相同的轨迹（已由单测锁定）。

### 2.2 旅行时间（实测修正）

- 旅行时间 = 出发格当前有效投射间隔 x 曼哈顿距离。正交相邻 1 格 = 1 倍，对角 = 2 倍，跨三格 = 3 倍。
- 时间在「出发瞬间」快照，之后该格获得任何增益都不追溯修改已在途的旅行。
- 跳过的中间格不触发、不参与联组。

### 2.3 冷却

| 位置 | 邻格数 | 基础冷却 |
| --- | --- | --- |
| 角位 | 2 | 1.5 s |
| 边位 | 3 | 2.0 s |
| 中心位 | 4 | 4.0 s |

- 冷却硬下限 1.2 s，投射间隔硬下限 0.8 s。
- 共鸣石对冷却与间隔同时生效，先乘算再夹下限。

### 2.4 路由

1. 每格持有一个配置出口集合，默认正交四邻（越界自动剔除）。
2. 禁止立即回到上一格；候选为空时允许回退（防止单出口死锁）。
3. 无可达出口时脉流消散，并在一个间隔后从起点重生。
4. 冷却受阻时最多改道 2 次，每次改道仍支付旅行时间，不做零时间递归；第 3 次受阻消散。
5. 断流铭文允许保留配置出口，但运行时终止传播，是「至少一个出口」规则的显式例外。

### 2.5 探索保底

- 连续 6 跳未踩到本轮新格时，强制跳向最近的未访问已解封格。
- 按曼哈顿距离收费；同距按格 id 升序；保底跳转会打断联组。
- 全部已解封格访问完后开启新一轮访问记录。
- 没有可跳目标时不清零计数，交由正常路由处理。

### 2.6 起点

- 第一幕 1 个起点，第二幕 1 个，第三幕 2 个。
- 起点跟随：把角色在战场中的归一化坐标映射到最近的一个已解封格，只在脉流重生时采样。
- 起点落地同样尝试触发，受冷却约束。

## 3. 方位映射

- 采用「角色相对的 4x4 近远区域」，不是 16 个等角扇区。
- 以角色为中心、半边长为 120 像素的正方形划分为 16 块，格 id 与区域 id 一一对应。
- 每格只攻击本区域内最近的敌人；同距按实体 id 升序。
- 区域为空时朝该区域中心空射，不跨区自动索敌——火力漏洞必须真实存在。
- 面板法阵是 UI 坐标，不参与战斗距离计算；过渡带光迹只是表现，伤害由战斗层单独计算。

## 4. 联组

### 4.1 判定

- 严格时序：只认「同一条脉流连续成功触发指定序列」。
- 组外绕路、跳序、冷却受阻、消散、保底传送、跨脉流拼接，全部断链。
- 首格成功时快照窗口：窗口 = 序列各边预计旅行时间之和 x 1.4。
- 截止时刻含等号（恰好到点仍成立）。
- 首格再次出现可立即重开一轮。

### 4.2 形状与结算

| 形状 | 格数 | 判定 | 结算 |
| --- | --- | --- | --- |
| 对偶 | 2 | 两个正交相邻格依次触发 | 两格各追加 20% 基础输出 |
| 直线三连 | 3 | 同行或同列三格依次触发 | 末格追加 40% |
| 折线三连 | 3 | L 形三格依次触发 | 组内各格追加 45% |
| 环封四格 | 4 | 2x2 四格依次遍历（不要求回到起点） | 组内各格追加 80% |

- 追加攻击是一次独立结算，不追溯已命中伤害，不永久累乘，不再触发联组递归。
- 「外圈八格」不实现：4x4 外周实际为 12 格，原稿形状不成立。

### 4.3 实测问题（待你确认的修正建议）

仿真显示：因为每跳必然落在正交相邻格，「对偶」几乎每次跳跃都会成立，180 秒单局触发约 205 次——它不是联组爆发，而是常驻增益。

建议改为「双向对偶」：必须是 A → B → A 的往返才算成立，把它从常态 buff 变成需要刻意构造的闭环。若不改，建议把对偶增益压到 +8% 以内并明确它是基础增益。

## 5. 数值表（首版默认值）

| 参数 | 第一幕 | 第二幕 | 第三幕 |
| --- | --- | --- | --- |
| 基础投射间隔 | 2.0 s | 1.7 s | 1.4 s |
| 起点数 | 1 | 1 | 2 |
| 解封格数 | 6 | 12 | 16 |
| 战斗时长 | 180 s | 240 s | 180 s |

- 共鸣石减幅 25%，影响正交四邻，乘算 0.75^n，不影响自身。
- 辅助饱和：首版不做隐藏递减，改为幕间显式提示「辅助占比过高」。
- 每局保证至少 2 张纯输出卡。

## 6. 实测修正汇总

由 scripts/simulate.mjs 用 8 个固定种子、每局 180 秒跑出：

1. 基础间隔 2.0 s 时，位置化冷却完全不起作用（受阻率 0.00%）。最短合法回路 4 跳 = 8 秒，已超过中心位 4 秒冷却。
2. 冷却要到间隔 ≤ 1.0 秒才开始吞跳；0.8 秒时受阻率 5.18%。
3. 第三幕单脉流实测只有 0.67 触发/秒，离设计稿「每秒 2 至 3 次」很远。单脉流触发率上限 = 起点数 / 间隔。要达标需要 3 至 4 个起点，或把间隔压到 0.4 秒（低于 0.8 秒下限）。
4. 共鸣石的真实收益远小于文档的 +33%：中心位实测 +6.8%，角位 +2.9%。原因是单脉流下邻格并不会等量增产。

这三条不影响 P0 逻辑正确性，但直接影响「构筑爽感」。等你拍板再调，默认仍按设计稿原值实现。

## 7. 新增 NPC 遭遇与 Boss 破局（设计已确认，未实现）

- 沿途多次问答，只有部分事件通向正式 Boss；题目依据本局已展示或当次对白提供的游戏内线索与规则。
- 正式 Boss 有固定前置互动：答对直接消灭该 Boss，免除整场危机；答错进入实际 Boss 战，不直接判死。
- 普通 NPC 答对领奖、答错触发提前告知的有限惩罚；具体题库、次数与数值仍待内容设计。
- 读题冻结战斗、脉流、冷却、增益、波次与幕计时，不允许改阵或无限重答。确认前清除沿用输入。
- 解谜处决与战斗击败共用 Boss 通关结算和基础奖励，不重复掉落；最终 Boss 处决后直接胜利，非最终 Boss 进入幕间。
- 遭遇按本局 ID＋遭遇 ID 去重，确认、处决、奖励与推进均幂等；处决时撤销 Boss 的待生成事件、召唤物和在途敌方攻击。
- 计时仅开启 Boss 遭遇，解决 Boss 后才结束本幕。先实现一个普通 NPC 与一个基础 Boss 的双路径，再扩充多个环节。
- 完整流程、示例与验收见[设计稿增补](<../共振法阵_游戏设计稿_v2.0.md#L1397>)。

## 8. 与设计稿的偏离清单

| 条目 | 设计稿 | 本契约 | 原因 |
| --- | --- | --- | --- |
| 辅助槽位 | 数据允许符印+辅助同格 | 互斥，单主槽 | 保住机会成本 |
| 联组断链 | 正文与示例代码不一致 | 严格同脉流连续 | 可实现、可归因 |
| 外圈八格 | 8 格外圈 | 不做 | 4x4 外周为 12 格 |
| 方位 | 16 方位扇区 | 4x4 近远区域 | 与「中心贴身、角位远端」自洽 |
| 竖屏 | 战场压成窄条 | 首版只支持横屏 | 已确认桌面优先 |
| 辅助递减 | 超 50% 每张 -15% | 改为显式提示 | 隐藏惩罚不可归因 |
