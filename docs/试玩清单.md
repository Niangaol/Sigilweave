# 试玩清单 · 五幕七场

> 逐条对照用。每条 `- [ ]` 是一次能当场验证的观察，括号里写预期结果和判断依据——HUD 字段、画面元素或一张截图，不靠「感觉还行」。
> 规则口径以[规则契约](<规则契约.md>)为准，幕与场的对应见[五幕七场](<五幕七场.md>)。卡住的项连同幕/场/等级/seed 与操作步骤一起记下来。

## 一、在哪跑、怎么记

| 方式 | 地址 / 命令 |
| --- | --- |
| 线上试玩 | <https://niangaol.github.io/Sigilweave/> |
| 本地开发 | `npm install` 后 `npm run dev` |
| 静态包 | `npm run build`，`node scripts/static-server.mjs dist 4174` |
| 桌面版 | 见[桌面打包](<desktop-build.md>)，异常用 `启动（兼容模式）.cmd` |

看顶栏：生命（带护盾显示 `100+10`）、`碎片 N`、`脉频 x.x/s`、`第N幕 · 星名/场名`、计时、`LV n`、`EXP a/b`；结算页另看八项数据与两行残响。

加速参数仅用于检查，不算平衡结论：

| 参数 | 作用 |
| --- | --- |
| `?seed=xxx` | 固定种子，复现要配同样的输入 |
| `?quick=1` | 经验 ×4，不跳 Boss、不跳幕间，结算残响 ×0.5 |
| `?scene=battle` | 跳过标题进战斗 |
| `?kit=bolt\|flame\|ward` | 指定起手职业，未知值回退疾风 |
| `?cine=0` | 关过场，截图与自动化用 |
| `?resonance=999` | 把残响灌到 999（**会写档**，验完清掉） |

## 二、开场 → 标题 → 选套

- [ ] 开场过场后可跳过；跳过后标题不黑屏、不重播。（依据：「共振法阵」大标题与开始提示）
- [ ] 标题按 H 开合玩法说明；面板开着时 B 不进祭坛。（依据：面板 8 行，含共鸣石、脉流、联组、断链、问答）
- [ ] 标题按 B 进祭坛、Esc 回标题，不再被弹回。
- [ ] Enter / 空格 / 点击进选套，三张卡是疾风、烈焰、壁垒，各写本命被动。
- [ ] 1 / 2 / 3 选套、Enter 或点按钮出战；三套开局法术与外观不同，解封格数一致。
- [ ] 首场开局：`LV 1`、`EXP 0/10`、`碎片 0`、计时 `00:00`，4 张符印全为「谐」。

## 三、每场探索

### 3.1 地图与镜头

- [ ] 往一个方向走 10 秒以上，世界持续滚动，不会撞到看不见的墙；HUD 与右下罗盘固定不动。
- [ ] 世界随场放大：场 1 是 2400×1800，场 7 是 3000×2200，换场后能感到更宽。
- [ ] 约 130 像素内浮出「名字（提示语）」，走开消失，不挡血条与时钟。
- [ ] 走进 **34 像素**自动开问答，不用按键；触发后人物停住、浮字消失。
- [ ] 已解决的事件点本局不再弹，换场后不复活；切出窗口自动暂停，回来仍是暂停。

### 3.2 问答

- [ ] NPC 答对：`碎片` +8、生命回 15（不超上限）；答错迟缓 8 秒后自然恢复。
- [ ] 读题期间敌人、脉流、冷却、计时全冻：站 10 秒血量不掉、计时不走。
- [ ] 1 / 2 / 3 或点击选答，再点确认；没选就确认只给提示，不提交。
- [ ] 34 条题都能从当次对白或碑文推出答案。（7 NPC + 20 小 Boss + 7 大 Boss）

### 3.3 小 Boss

- [ ] 场 1-3 各 4 只（a~d）、场 4-7 各 2 只（a/b），共 20 只，名字带方位或场地后缀。
- [ ] 答对直接解决、不播战斗；答错进战，进场约 0.9 秒。
- [ ] 解决后回本场探索：**不**弹幕间、**不**通幕、不算通幕进度。
- [ ] 收据只发一次：基础 6 碎片，答对再 +6（共 12），另给本场固定法术卡与随机罗盘增益；小 Boss 战里敌人不会躲到屏外。

### 3.4 大 Boss

- [ ] 按等级触发，门槛 5 / 10 / 15 / 20 / 24 / 28 / 32；不清完事件点也会触发，不是计时。
- [ ] 先出前置问答：答对直接解除契约免战，答错播进场（约 1.6 秒）实战。
- [ ] 七套弹幕各一场，预警 600ms 看得懂方向；没有多阶段、没有召唤。
- [ ] 收据 12 碎片，答对再 +4（共 16），另给本场固定法术卡与随机罗盘增益；同一场只开一次。

### 3.5 换场与通幕

- [ ] 场 1 / 2 / 3 / 5 的大 Boss 后出通幕卡进幕间（全流程 4 次）。
- [ ] 场 4、场 6 后**原地换场**：场次卡停 1.6 秒，不出工作台，血量、构筑、碎片、等级经验全保留。
- [ ] 场 7 后进结局演出，再落「契约终结」结算页。
- [ ] 换场后幕标题会变（第 4 幕从「沉钟书库」到「衡律法庭」），数值连续；在飞的青色经验粒子会被结算掉。

## 四、升级与构筑

- [ ] 经验：普通 1 点、天生精英 6 点；每 20 秒有效战斗再给 1 点，读题与暂停不推进。
- [ ] 阈值 `round(6 × L^1.15) + 4`，HUD 的 `EXP a/b` 分母与当前等级需求一致。
- [ ] 击杀经验先飞青色粒子，追到身上才涨；0.3~1.5 秒延迟是设计。
- [ ] 升级立刻暂停，三选一三张不同，点击或 1 / 2 / 3 领取；卡进手牌，**不自动上阵**；连升两级逐次选牌。
- [ ] 幕间三轮：首轮只出基础四输出，后两轮完整池（24 符印 + 6 辅助）；领过的轮次不能再领。
- [ ] 守恒：手牌数减已装格数始终对得上，拆下的卡回手牌。
- [ ] 定向辅助必须绑相邻输出格；绑不上时出发按钮不可用并给原因。
- [ ] 铭文单枚 8 碎片、每格两槽、同名不重复，拆一枚返 4；誓约全局最多一个；出口可改断流，但至少留一条出口。
- [ ] 出发条件：三轮领完、至少两张未装中继的输出、校验无错。

## 五、暂停与编辑法阵

- [ ] Esc 开暂停：「暂　停」+「战场与脉流已冻结」，四项音效 / R 重开 / T 返回标题 / E 编辑法阵都能点。
- [ ] 按住空格看细目、松开继续；空格期间不误触编辑。
- [ ] 编辑三步：选牌 → 点空符位放置 → 绑目标或收回；手牌一页五项，左右箭头切页。拿下再放回同一格，冷却**不刷新**（盯该格冷却圈，剩余应连续）。
- [ ] 编辑完回暂停菜单要手动继续；读题与升级选择时按 E 不进编辑，不会两层面板叠着。

## 六、敌人、变体与可读性

- [ ] 26 种（19 普通 + 7 天生精英）按幕权重出；幕 1 只有 4 种杂兵，幕 4、5 各带 6 种专属。
- [ ] 3 种变体叠在基础怪上，名字带前缀：疾行、重甲、精英；天生精英不叠变体。
- [ ] 重甲怪出生带护甲，先掉护甲再掉血；破甲瞬间 400ms 硬直、肩甲与盾消失，接触伤害回基础值。
- [ ] 近战有扇形前摇、远程是弹丸；炮台、符文、召唤物出现有独立表现，且不算击杀数。
- [ ] 同屏密度随场抬升（上限 34→66 再乘场系数，场 7 约 107 只），四周持续进怪，不长时间空场。
- [ ] 「连斩 ×N」在连续击杀时出现，1.5 秒无新击杀就断；每 12 连斩回 1 血，20/40/60 连斩轻震屏。
- [ ] 法术击杀会尸爆，波及 30 像素内其他敌人（其最大生命 50%）并连锁，同一只只爆一次。
- [ ] 受击无敌 1400ms，贴脸不被秒；画框随血量分三级磨损（>60% 完好、>30% 磨损、更低濒碎）。
- [ ] 屏幕内无可选目标时输出符印停火等待，不朝屏外画光迹。

## 七、死亡、通关与结算

- [ ] 死亡播过场进结算：标题「魂火熄灭」，副标题「第 N 幕 · 挑战中断」。
- [ ] 八项数据齐全：存活时间、击杀数、符文碎片、脉流触发、联组成立、冷却受阻、峰值脉频、解锁符位。
- [ ] 有「残响 +N」与「残响累计 M」两行，M 等于祭坛右上角余额；新节点显示「新契约 · 名称 +奖励」，最多三条。
- [ ] Enter / R 或点击再战，Esc 回标题，两个入口都不重复结算。
- [ ] 通关标题「契约终结」，副标题「七位契约主已消灭 · 通关」。
- [ ] `?stress=1` 或中途关页不结算：余额不变。

## 八、残响祭坛

- [ ] 标题按 B 或地址加 `?scene=meta` 直达；Tab 在「残响祭坛」与「契约图鉴」间切。
- [ ] 被动页 11 行：左列 5 条人物被动、右列 6 条罗盘被动，每行有名字、`Lv.x/上限`、残响价、一句效果。
- [ ] 选中行黄铜描边；买得起亮青、买不起血红；被上限拦写「需首杀」，满级写「已满级」。
- [ ] Enter / Space 升级，余额立刻减少，底部出现「XX 升至 Lv.N」；↑↓ / WASD 移动，到列尾翻列，连按不跳格。
- [ ] 图鉴 34 格（6 列 × 6 行）：未点亮 `???`，点亮显示名称与 `+奖励`；boss-3 / 5 / 7 额外标「上限→3/4/5」。
- [ ] Esc 回标题再按 B，等级与余额都在；重启浏览器也在。

## 九、存档与坏档

- [ ] 局外档在 `localStorage` 的 `sigilweave:meta:v1`；局内一局只在内存，刷新即丢且不结算残响。
- [ ] 控制台执行 `localStorage.setItem('sigilweave:meta:v1','{"resonance":"x"}')` 后刷新：标题能进、余额 0、11 条全 0 级。
- [ ] 越界收敛：等级写 99 读出 5，`counters.bestAct` 写 99 读出 5，未知或重复节点被丢弃且不报错。
- [ ] 隐私模式或禁存储不白屏：没有 `localStorage` 就退进程内内存档。
- [ ] `?resonance=999` 会写真实存档，验完用 `localStorage.removeItem('sigilweave:meta:v1')` 清掉。
