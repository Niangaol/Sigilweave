# P3 遭遇问答与 Boss 双路径验收

> 状态：问答系统与 Boss 双路径已实现并通过浏览器回归；完整 25 项卡池、更多敌人类型、出口编辑 UI 尚未完成，不宣称 P3 整体结束。

## 已实现

- **沿途 NPC 问答**：每幕中点（计时 50%）触发一名 NPC——第一幕守灯人艾琳、第二幕巡礼者瑟维安、第三幕织誓者莉芙拉。题目三选一，答案只能由当次展示的线索直接推得。
- **NPC 奖惩**：答对 +8 碎片并治疗 15 点生命；答错承受 8 秒迟缓诅咒（移动速度 ×0.75），不判死、不扣装备。
- **Boss 固定前置问答**：每幕计时结束时先进入问答，Boss 已在场但战斗冻结。答对——呼出真名／割断誓绳——**直接消灭该 Boss**（烬冠骑士／溺誓女爵／无昼织王），免除整场战斗；答错进入真实 Boss 战。
- **Boss 实战**：答错后杂兵清空，Boss 追击玩家（55px 停距），每轮攻击有 600ms 红色瞄准线预警，随后发射五向扇形弹丸（伤害 8）；弹丸可被走位躲开，命中扣血。
- **统一通关结算**：问答处决与战斗击败写入同一份 bossResolutions 收据（基础奖励 12 碎片，不重复发放），答对额外 +4。第三幕 Boss 解决后进入最终胜利结算，记录破局／战斗击败次数。
- **读题全冻结**：问答期间脉流引擎、敌人、弹丸、波次、玩家移动、幕计时全部停止；选项打乱后仍按稳定 ID 判题；confirm／finish 幂等，每次遭遇每局只触发一次；失焦后关闭对话不会悄悄恢复战斗。
