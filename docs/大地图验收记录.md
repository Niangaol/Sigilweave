## 5. 可读性、索敌与拥挤修订（本轮）

用户实机反馈三条：文字一大半看不清、攻击像只锁屏幕内、怪会堆在一起。根因与处理如下。

| 反馈 | 根因 | 处理与验证 |
| --- | --- | --- |
| 文字看不清 | 旧版固定 480×270 画布再交给浏览器拉伸，屏幕越大糊得越狠；9px 宋体在小字号下笔画直接糊掉 | 画布与文字纹理按窗口取**整数倍率原生渲染**（1080p = 4×、1440p = 5×、上限 8），可见世界恒为 480×270，游戏坐标一处未改；正文字体换微软雅黑/苹方/思源黑，大标题保留衬线；浅色底上的深色文字关闭描边，深色底文字加一圈深色描边提对比。实测 1920×1080 下 backing store 与 CSS 尺寸均为 1920×1080（1:1 无拉伸），见[文字截图](<text-title-1920.png>)、[选包](<text-loadout-1920.png>)、[战斗](<text-battle-1920.png>)、[幕间](<text-intermission-1920.png>)、[结算](<text-gameover-1920.png>) |
| 只锁屏幕内 | 区域是固定 ±120px 小方格，而敌人刷在 140–520px 环上，大半敌人根本不在任何区域内，只能等本区空掉后的补射 | 16 个区域改为覆盖全图的相对条带：列 = 屏左外/左半屏/右半屏/屏右外，行 = 屏上外/上半屏/下半屏/屏下外；任何坐标必属于一个区域。实测灌满 26 只后有 15 只在屏幕外，且**屏幕外的敌人确实被扣血**（[索敌与拥挤回归](<../scripts/targeting-smoke.mjs>)断言 `offscreenHurt ≥ 1`） |
| 怪堆在一起 | 旧落点环只有 60px 宽、无间距检查，全部朝玩家直冲 | 同屏上限 7→22 提升到 9→26；落点环加宽到 230–430 且要求与已有敌人 ≥36px，取不到就退回“最不拥挤”的候选点；逐帧轻量分离 gap 24（超过 48 只时跳过，避免压测 O(n²)）。实测 26 只时最近间距 45px，与玩家距离 190–413px |

相关单测：[索敌与刷怪](<../tests/logic.test.js>)、[落点与分离](<../tests/spawn.test.js>)、[HUD](<../tests/hud.test.js>)。

### 方阵区位装饰（本轮新增）

16 格按位置分三种装饰，战斗罗盘与幕间大盘共用同一份规则（[board-decor.js](<../src/ui/board-decor.js>)）：

| 区位 | 格号（1 起） | 装饰 |
| --- | --- | --- |
| 角落 ×4 | 1 / 4 / 13 / 16 | 两条外侧边各压内外两线形成黄铜护角，外角一颗 2×2 铆钉，石面略暗 |

### 交互统一到鼠标（本轮）

反馈原文：选项选择部分有些能用鼠标、有些只能按键。审计后发现真正缺的是**暂停菜单**——它注释写着“纯键盘操作”，四项（继续/重开/返回标题/编辑法阵）没有任何命中区，只能按 Esc/R/T/E。

改动：

- 暂停菜单每一行变成 220×16 的逻辑热区，指针按渲染倍率折算后与行矩形比较；点击与键盘快捷键调用同一组 `actions`，不会出现两套行为。
- 鼠标悬停在哪一行，哪一行高亮描边（`pxRect` + `pxFrame`），让“这里能点”可见；菜单底部提示改为“点击选项，或按对应按键”。效果见[暂停菜单悬停](<pause-menu.png>)。
- 其余界面复核确认已可用鼠标：标题点击开始、选包卡片与出战按钮、升级三选一、遭遇选项与确认、暂停编辑法阵与完成、幕间工作台全部按钮、结算页再战。

验证：

- 单测 `hitRowAt`：四行命中、文字两端仍命中、行外与面板外不误触、非法输入返回 -1。
- 新增浏览器审计 [pointer-smoke](<../scripts/pointer-smoke.mjs>)：在 1920×1080（倍率 4）下真实点击 9 条路径——标题开始 → 选包切卡（bolt→flame）→ 点按钮出战 → 点升级卡（手牌 0→1）→ 点暂停“编辑法阵” → 点“完成” → 点“继续战斗” → 点“返回标题” → 点“重开本局”（bootCount 增加）→ 结算页点一下再战，全部断言通过，pageerror 为零。

### 幕间罗盘配置页美化（本轮）

反馈：罗盘配置页太简陋。原来那一页只是把文字和按钮按坐标摆开——没有分区、没有图标、没有悬停反馈，格子里只有一行字。

重做（命中区坐标全部保持不变，交互行为与回归脚本零迁移）：

- **分区面板**：外框双线 + 四角铆钉，奖励区、法阵区、统计区、手牌区各自独立成板，不再是一片散落的文字。
- **格内图标**：4×4 每格显示该法术的 8×8 字模 + 名称 + 「铭/出/指向」明细；封印格是压暗底 + 菱形。
- **手牌列表**：带内框的列表容器，行内是图标 + 名称 + 右对齐效果说明，选中行整条符文高亮。
- **铭文按钮**：熔炉/中继/断流/静默各有 8×8 图标，与符印同一套字模规范。
- **悬停反馈**：鼠标移到格子、手牌、按钮上会亮起黄铜细框。高亮画在独立图层，只清这一层，不重建整页文字。
- **背景层次**：硬边竖纹 + 三层硬边压暗（全程平滑渐变仍是禁止项）。
- 顺手修了一个真 bug：手牌统计在使用之前才声明，触发了 TDZ，会把整页绘制打断。

验证：`drawGlyph` 与四种铭文图标各加了单测（8×8、非空、两两不同、坐标与缩放正确）。截图：[美化后工作台](<text-intermission-1920.png>)。

新增单测 [new-sigils](<../tests/new-sigils.test.js>) 15 项：符印共 16、每张都有 8×8 字模且非空白、**16 张两两不同**（杜绝共用兜底图）、卡池符印都在定义表且都有图标；另有连锁衰减/半径外不跳、贯穿走廊与射程、回声双侧与去重、陨星内圈 60%、圣环 60 上限、噬魂回血封顶、地裂定身、余烬减速。

### 已知取舍

- 1440p 时整数倍率取 5，画布 2400×1350 会被浏览器放大到 2560×1440（约 1.07×，最近邻），不是严格 1:1；比旧版 5.3× 拉伸好得多，但没有完全消除。
- 高倍率下像素画每个逻辑像素占 4–5 个设备像素，观感比 480×270 时代更“块”，这是整数缩放的必然结果。
