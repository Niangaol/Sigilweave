## 2. 本轮补查并修复的问题

- 冷却冒烟原先只读取变量而未断言；现注入非零未来截止时间，装入/收回/退出编辑全过程检查模拟时钟与所有格冷却不变。
- E 绑定误替换 M、Esc 可在编辑界面仍打开时恢复战斗、编辑监听未清理；均已修复。暂停菜单文字固定视口，E 提示和诊断分行；手牌五项分页防止大量卡片遮挡完成按钮。
- 罗盘冷却倍率、命中范围、联组窗口，以及人物移速、拾取吸附范围、额外无敌时间、护盾上限原有部分只存数值而未作用到玩法；现已接入并测试。
- 连续生命宝箱重复叠加已计入 maxHp 的 bonus；修复后连续两次 +20 得到 140，不是 160。人物增益写入本局并跨场景保留。
- Boss 定义没有 cardKey，原条件分支不发法术；现每幕固定寒霜箭 / 圣光壁垒 / 星陨，与 tier 收据一起防重复。
- HUD 原本只收到成长数据但没有绘制 LV/经验，且已有顶栏文字随世界滚走；现补齐独立第二行 LV、EXP 与经验条，所有顶栏文字固定视口，经验分母取当前 L 而不是 L+1，并新增[HUD 单测](<../tests/hud.test.js>)与真实移动 80 像素后的镜头/文字固定断言。
- 跨幕背景构造先于 world 更新导致沿用上一幕尺寸，现先初始化本幕世界并加三幕断言。
- 压测实体坐标改为玩家附近的世界坐标，禁用仅压测模式中的升级/问答弹出，并断言模拟时钟持续推进，不能用暂停空帧作为高负载性能。正常游玩不受此压测开关影响。

### 复现

先在一个终端启动静态服务：

```bash
npm ci
npm test
npm run build
node scripts/static-server.mjs dist 4173
```

另一个终端执行（Node 统一入口，无需额外 shell 环境语法；默认验证上述 4173）：

```bash
node scripts/acceptance.mjs
node scripts/check-docs.mjs
```

浏览器脚本使用已安装的系统 Edge 和 Playwright；长时压测需约两分钟，全部验收另需主流程操作时间。

## 5. 可读性、索敌与拥挤修订（本轮）

用户实机反馈三条：文字一大半看不清、攻击像只锁屏幕内、怪会堆在一起。根因与处理如下。

| 反馈 | 根因 | 处理与验证 |
| --- | --- | --- |
| 文字看不清 | 旧版固定 480×270 画布再交给浏览器拉伸，屏幕越大糊得越狠；9px 宋体在小字号下笔画直接糊掉 | 画布与文字纹理按窗口取**整数倍率原生渲染**（1080p = 4×、1440p = 5×、上限 8），可见世界恒为 480×270，游戏坐标一处未改；正文字体换微软雅黑/苹方/思源黑，大标题保留衬线；浅色底上的深色文字关闭描边，深色底文字加一圈深色描边提对比。实测 1920×1080 下 backing store 与 CSS 尺寸均为 1920×1080（1:1 无拉伸），见[文字截图](<text-title-1920.png>)、[选包](<text-loadout-1920.png>)、[战斗](<text-battle-1920.png>)、[幕间](<text-intermission-1920.png>)、[结算](<text-gameover-1920.png>) |
| 只锁屏幕内 | 区域是固定 ±120px 小方格，而敌人刷在 140–520px 环上，大半敌人根本不在任何区域内，只能等本区空掉后的补射 | 16 个区域改为覆盖全图的相对条带：列 = 屏左外/左半屏/右半屏/屏右外，行 = 屏上外/上半屏/下半屏/屏下外；任何坐标必属于一个区域。实测灌满 26 只后有 15 只在屏幕外，且**屏幕外的敌人确实被扣血**（[索敌与拥挤回归](<../scripts/targeting-smoke.mjs>)断言 `offscreenHurt ≥ 1`） |
| 怪堆在一起 | 旧落点环只有 60px 宽、无间距检查，全部朝玩家直冲 | 同屏上限 7→22 提升到 9→26；落点环加宽到 230–430 且要求与已有敌人 ≥36px，取不到就退回“最不拥挤”的候选点；逐帧轻量分离 gap 24（超过 48 只时跳过，避免压测 O(n²)）。实测 26 只时最近间距 45px，与玩家距离 190–413px |

相关单测：[索敌与刷怪](<../tests/logic.test.js>)、[落点与分离](<../tests/spawn.test.js>)、[HUD](<../tests/hud.test.js>)。

### 其它顺带修正

- HUD 顶栏换字后变宽互相压字（`100+14` 撞 `碎片 0`、时间被右缘裁掉），已重排间距与文案。
- 结算页底部两行溢出面板、深色字被深色描边糊住，已上移并把品牌行移到面板外。
- `EffectsLayer` 手写的“世界→屏幕”换算假设了 zoom=1，改按 `worldView` 计算，否则光迹终点会偏。
- 暂停编辑与升级三选一的点击命中区是逻辑坐标，指针给的是游戏像素，已按倍率折算。

### 已知取舍

- 1440p 时整数倍率取 5，画布 2400×1350 会被浏览器放大到 2560×1440（约 1.07×，最近邻），不是严格 1:1；比旧版 5.3× 拉伸好得多，但没有完全消除。
- 高倍率下像素画每个逻辑像素占 4–5 个设备像素，观感比 480×270 时代更“块”，这是整数缩放的必然结果。

## 6. 非本次冻结交付的边界

- 仍为点选，不支持拖放；只有合成音效，没有背景配乐。
- 未进行新玩家理解度/平衡乐趣的人类试玩；小字号像素中文字仍需人类可读性反馈。
- 桌面键鼠优先，移动端/触摸未适配。
- 性能数据为 headless Edge 自动化环境，不代替真机 GPU、多浏览器性能结论。
- 问答/三幕回归会注入等级、位置和部分战斗结束条件来覆盖分支，不等同于纯人工自然游玩通关；经验曲线和敌人行为另有独立单测。
