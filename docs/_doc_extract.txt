# 《共振法阵》美术素材交付 v1.0
适配环境：Phaser3 + Vite | 画布480×270 | pixelArt:true | 正交2.5D斜俯视（isometric）
美术风格对标：Loop Hero 循环勇士像素，硬色块、无平滑渐变、透明背景PNG
✅ 重要统一规则（所有角色必须遵守！）
1. 精灵原点：全部角色 `setOrigin(0.5,1)`  X居中，Y=1对齐脚底，防止角色悬浮
2. 渲染深度：战场单位update每帧执行 `sprite.setDepth(sprite.y)`，按Y坐标排序，解决遮挡
3. 项目配置确认：main.js config里面 `pixelArt: true, roundPixels: true`，防止像素模糊

## 📌 preload 预加载代码（直接粘贴进Battle场景 preload()）
```javascript
preload() {
    // 动画精灵表 spritesheet
    this.load.spritesheet('player', 'assets/sprites/player_sheet.png', {frameWidth:32, frameHeight:32});
    this.load.spritesheet('skeleton', 'assets/sprites/skeleton_sheet.png', {frameWidth:28, frameHeight:28});
    this.load.spritesheet('corpse', 'assets/sprites/corpse_sheet.png', {frameWidth:30, frameHeight:30});

    // 单帧静态怪物
    this.load.image('undead_bat', 'assets/sprites/undead_bat.png');
    this.load.image('gargoyle', 'assets/sprites/gargoyle.png');
    this.load.image('cultist', 'assets/sprites/cultist.png');
    this.load.image('ghoul', 'assets/sprites/ghoul.png');
    this.load.image('death_knight', 'assets/sprites/death_knight.png');
    this.load.image('lesser_demon', 'assets/sprites/lesser_demon.png');
    this.load.image('lich', 'assets/sprites/lich.png');

    // 特效拾取物
    this.load.image('rune_shard','assets/effects/rune_shard.png');
    this.load.image('attack_warning','assets/effects/attack_warning.png');
}
